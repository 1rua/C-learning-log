## 一、判断题（共 5 题）

### 1. 若有定义 `double a = 7 / 2;`，则变量 `a` 的值精确为 `3.5`。
- [ ] 正确 (T)
- [x] 错误 (F)

> **考点**：整数除法截断。`7/2` 的操作数均为 `int`，先执行整数除法得 `3`，再隐式转换为 `double` 存为 `3.0`。若要得到 `3.5`，需写作 `7.0/2` 或 `7/2.0`。

---

### 2. 在函数内部返回一个非 static 的局部变量的地址，外部指针接收后依然可以长期安全稳定地访问该内存。
- [ ] 正确 (T)
- [x] 错误 (F)

> **考点**：悬垂指针与栈生命周期。非 static 局部变量随函数栈帧销毁而回收，返回其地址属于未定义行为（UB）。只有返回 `static`、堆内存（`malloc`）或外部传入的指针才合法。

---

### 3. 在同一个一维数组中，两个同类型指针相减（`p2 - p1`），其结果等于两指针内存地址相差的字节数。
- [ ] 正确 (T)
- [x] 错误 (F)

> **考点**：指针算术运算。指针相减计算的是两个指针之间的**元素个数差**，底层会自动除以 `sizeof(T)`，而非直接的物理字节地址差。

---

### 4. 结构体指针访问其成员时，表达式 `p->name` 在语义和功能上完全等价于 `(*p).name`。
- [x] 正确 (T)
- [ ] 错误 (F)

> **考点**：结构体成员访问语法糖。点运算符 `.` 用于结构体实体变量，箭头运算符 `->` 用于指针。由于 `.` 优先级高于 `*`，必须写成 `(*p).name`，C 语言引入 `->` 作为完全等价的语法糖。

---

### 5. 设 `int a = 5; int b = a++;` 执行后，变量 `b` 的值为 5，`a` 的值为 6。
- [x] 正确 (T)
- [ ] 错误 (F)

> **考点**：后置自增运算符。`a++` 为先用后加，表达式返回旧值 `5` 赋给 `b`，随后 `a` 自增为 `6`。

## 二、单项选择题（共 5 题）

### 6. 执行以下代码段后，输出结果是（ ）。
```c
int k = 1, s = 0;
switch (k) {
    case 1: s += 2;
    case 2: s += 3;
    case 3: s += 4; break;
    default: s += 5;
}
printf("%d\n", s);
```
- [ ] A. 2
- [ ] B. 5
- [x] C. 9
- [ ] D. 14

> **考点**：`switch` 的穿透（fall-through）特性。`k=1` 匹配 `case 1` 进入，由于未写 `break`，连续执行 `case 1`、`case 2`、`case 3`（`s = 2 + 3 + 4 = 9`），遇 `break` 终止跳出。

---

### 7. 下列程序的输出结果是（ ）。
```c
void modify(int x) {
    x = 100;
}
int main(void) {
    int a = 10;
    modify(a);
    printf("%d\n", a);
    return 0;
}
```
- [x] A. 10
- [ ] B. 100
- [ ] C. 0
- [ ] D. 编译错误

> **考点**：函数值传递。形参 `x` 是实参 `a` 的拷贝副本，函数内修改形参绝不影响外部变量 `a`。修改外部变量必须传入地址 `&a` 并在形参中使用指针解引用。

---

### 8. 假设在 64 位系统且 `sizeof(int) == 4` 的环境下，有定义：`int (*p)[4];`，则 `sizeof(*p)` 的值是（ ）。
- [ ] A. 4
- [ ] B. 8
- [x] C. 16
- [ ] D. 32

> **考点**：数组指针定义与解引用大小。`p` 是指向包含 4 个 `int` 的一维数组的指针，`*p` 即为该数组本身，大小为 `4 * sizeof(int) = 16` 字节。注意 `sizeof(p)` 为指针自身大小（8 字节）。

---

### 9. 已有二维数组定义 `int a[3][3] = {{1,2,3}, {4,5,6}, {7,8,9}};`，指针 `int (*p)[3] = a;`，则表达式 `*(*(p + 1) + 2)` 的值是（ ）。
- [ ] A. 4
- [ ] B. 5
- [x] C. 6
- [ ] D. 8

> **考点**：数组指针跨行与二维寻址。`p+1` 跨过一整行指向第 1 行（第二行），`*(p+1)` 降维为第 1 行首元素地址，再 `+2` 指向第 2 列元素，解引用得到 `a[1][2]`，即 `6`。

---

### 10. 下列代码段执行后，输出结果是（ ）。
```c
int a[5] = {10, 20, 30, 40, 50};
int *p1 = &a[1];
int *p2 = &a[4];
printf("%ld\n", p2 - p1);
```
- [x] A. 3
- [ ] B. 12
- [ ] C. 4
- [ ] D. 地址随机值

> **考点**：指针相减下标差。`p2` 指向 `a[4]`，`p1` 指向 `a[1]`，同数组两指针相减返回下标跨越的元素个数：`4 - 1 = 3`。
