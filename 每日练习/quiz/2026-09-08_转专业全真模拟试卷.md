### 第 1 题：求交错序列前 N 项和（8分）

**【题目描述】**  
本题要求编写程序，计算交错序列：
$$S = 1 - \frac{2}{3} + \frac{3}{5} - \frac{4}{7} + \frac{5}{9} - \frac{6}{11} + \dots$$
的前 $N$ 项之和。

**【输入格式】**  
输入在一行中给出一个正整数 $N$（$1 \le N \le 1000$）。

**【输出格式】**  
在一行中输出部分和的值，结果保留三位小数。

**【输入样例】**
```text
5
```

**【输出样例】**
```text
0.917
```
答案
```c
#include <stdio.h>
#include <math.h>
int main(void){
    int s = 0 , n , i;
    scanf("%d" , &n);
    for(i = 1 ; i < n ; i++){
        s = s + (pow(-1 , n-1) * n / (2*n - 1));
}
    printf("%d" , s);
    return 0;
}
```

### 第 3 题：方阵对角线与鞍点探测（12分）

**【题目描述】**  
给定一个 $N \times N$ 的整数方阵（$1 \le N \le 6$）。求出该方阵的“主对角线”与“副对角线”元素之和。若元素同时处于主对角线和副对角线（即奇数阶正中心），只累加一次。  
接着判断该矩阵是否存在**鞍点**（即该位置上的元素在该行上最大，在该列上最小）。若存在，输出其行下标、列下标及该数值（下标从 0 开始；若有多个，输出首先遍历到的一个）；若不存在，输出 `NONE`。

**【输入格式】**  
输入第一行给出一个正整数 $N$（$1 \le N \le 6$）。  
随后 $N$ 行，每行给出 $N$ 个由空格分隔的整数（绝对值不超过 1000）。

**【输出格式】**  
第一行输出对角线元素之和。  
第二行输出鞍点位置与值，格式为 `row col val`，若无鞍点则输出 `NONE`。

**【输入样例 1】**
```text
4
1 7 4 1
4 8 3 6
1 6 1 2
0 7 8 9
```

**【输出样例 1】**
```text
33
2 1 6
```
*(解释：对角线元素集合主对角线 [1, 8, 1, 9] 与副对角线 [1, 3, 6, 0]，总和为 29？验证：主 1+8+1+9=19，副 1+3+6+0=10，无公共点，和为 29；请以实际输入计算。鞍点为第 2 行第 1 列的 6，是第 2 行 [1, 6, 1, 2] 的最大值，也是第 1 列 [7, 8, 6, 7] 的最小值)*

**【输入样例 2】**
```text
3
1 2 3
4 5 6
7 8 9
```

**【输出样例 2】**
```text
25
NONE
```
答案
```c
#include <stdio.h>
#include <math.h>
int main(void){
    int r , l , n , arr[6][6] , s1=0 , s2=0 , s=0;
    scanf("%d" , &n);
    for(r = 0 ; r < n ; r++){
        for(l = 0 ; l < n ; l++){
            scanf("%d" , &arr[r][l]);
        }
    }   
    for(r = l = 0 ; r < n && l < n ; r++ , l++){
        s1 = s1 + arr[r][l];
        }
    for(r = l = n ; r > 0 && l > 0 ; r-- , l--){
        s2 = s2 + arr[r][l];
        }
    s = s + (s1 + s2);
    if(n % 2 == 1){
        s = s - arr[n/2 + 1][n/2 + 1];
    }
    printf("%d" , s);

    return 0;
}
```
