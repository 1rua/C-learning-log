## 错误记录

### 一、流程控制与表达式

#### 错题 2：整数除法陷阱
- **用户答案**：A（2.5）
- **正确答案**：B（2）
- **表现**：以为 `double y = 5/2` 会得到 2.5
- **原因**：`5/2` 两个操作数都是 `int`，先做整数除法得 `2`，再赋给 `double` 时已经是 `2`。`%g` 输出 `2`（不显示小数点后多余的 0）
- **正确做法**：要得 2.5 需写 `5.0/2` 或 `5/2.0`

#### 错题 3：switch 贯穿（fall-through）
- **用户答案**：D（编译错误）
- **正确答案**：C（5）
- **表现**：以为缺 `break` 会编译错误
- **原因**：`switch` 在 C 中缺 `break` 是合法的，会从匹配的 `case` 一直贯穿到 `switch` 结束。`k=2` 进 `case 2`，`s+=2=2`，然后贯穿 `case 3`，`s+=3=5`
- **正确做法**：理解 `switch` 的 fall-through 机制，`break` 是可选的而非必须的

#### 错题 5：while 循环条件判断
- **用户答案**：D（无限循环）
- **正确答案**：B（4）
- **表现**：以为 `while(n)` 不会终止
- **原因**：`n` 初始为 1234，每次 `n/=10` 砍掉末位，4 次后 `n=0`，`while(0)` 条件为假，循环终止
- **正确做法**：逐轮推演 n 的变化：1234→123→12→1→0

#### 询问 1：三目运算符 `? :`
- **问题**：不知道冒号什么意思
- **知识点**：三目运算符 `条件 ? 表达式1 : 表达式2`，右结合。`a>b ? a : c>b ? c : b` 等价于 `a>b ? a : (c>b ? c : b)`
- **结果**：答案选对（C），但需要巩固

#### 询问 4：`continue` 的含义
- **问题**：以为答案是 18（3+6+9）
- **知识点**：`continue` = 跳过本轮循环剩余部分，被跳过的数**不参与累加**
- **结果**：经讲解后纠正为 37（B），正确

### 二、数组与字符串

#### 询问 6：多维数组下标计算
- **问题**：`a[0]` 是什么
- **知识点**：`a[0]` 是 `int*`，指向第一行首元素。`p+4` 在连续内存上跳 4 个 int（跨行不关心边界）
- **结果**：答案选对（A），但需要巩固

#### 询问 8：strcat、strlen、sizeof
- **问题**：strcat 是什么，strlen 和 sizeof 区别
- **知识点**：
  - `strcat(dest, src)`：拼接字符串到 dest
  - `strlen`：字符串实际长度（不含 `\0`）
  - `sizeof`：数组声明时的大小（含 `\0`）
- **结果**：答案选对（B），但需要巩固

### 三、函数与递归

#### 错题 11：值传递
- **用户答案**：A（100）
- **正确答案**：B（5）
- **表现**：以为函数内修改形参会改变实参
- **原因**：C 语言默认**值传递**，形参是实参的拷贝，函数内改 `x` 不影响 `main` 中的 `a`
- **正确做法**：要修改原变量需传指针（如第 15 题的 `swap`）

#### 询问 12：static 静态局部变量
- **问题**：static 是什么
- **知识点**：`static` 局部变量只初始化一次，值跨调用保留，生命周期与程序相同
- **结果**：答案选对（C），但需要巩固

#### 询问 13：递归两个 return
- **问题**：为什么有两个 return
- **知识点**：递归函数 = 终止条件（`return 1`）+ 递归体（`return n * f(n-1)`），两者不会同时执行
- **结果**：答案选对（C），但需要巩固

#### 询问 14：递归终止条件（无 return）
- **问题**：没有 return 怎么终止
- **知识点**：`void` 递归用 `if` 条件控制终止，条件不成立时自然跳过、函数返回
- **结果**：答案选对（B），但需要巩固

#### 询问 15：swap 指针交换
- **问题**：swap 什么意思
- **知识点**：通过指针参数实现两数交换，传地址而非传值
- **结果**：答案选对（B），已理解

### 四、指针

#### 错题 17：指针相减
- **用户答案**：D（地址差）
- **正确答案**：A（3）
- **表现**：以为指针相减得到地址差
- **原因**：同一数组内两个指针相减 = 它们之间的**元素个数**，不是字节差。`p = a+3`，`p-a = 3`
- **正确做法**：指针相减结果 = 偏移量差 / sizeof(元素类型)

#### 错题 18：数组指针 sizeof
- **用户答案**：A（4）
- **正确答案**：C（12）
- **表现**：以为 `sizeof(*p)` 是指针大小
- **原因**：`int (*p)[3]`，`*p` 是长度为 3 的 int 数组，`sizeof(*p) = 3 × 4 = 12`
- **正确做法**：区分 `sizeof(p)`（指针本身 8 字节）和 `sizeof(*p)`（指向的数组）

#### 错题 19：悬垂指针
- **用户答案**：A（正常输出 5）
- **正确答案**：B（返回局部地址，行为未定义）
- **表现**：没意识到返回局部变量地址的危险
- **原因**：局部变量 `x` 在函数返回后内存被回收，返回其地址形成悬垂指针，解引用是未定义行为
- **正确做法**：不要返回局部变量的地址；如需返回指针，用 `static`、`malloc` 或通过参数传回

#### 错题 20：指针重指向字符串
- **用户答案**：D（编译错误）
- **正确答案**：B（ok）
- **表现**：以为 `p="ok"` 会编译错误
- **原因**：`char *p` 是指针变量，可以重新指向另一个字符串常量。`p="hi"` 然后 `p="ok"` 是合法的，只是改变指向，不修改内容
- **正确做法**：区分"修改指针指向"（合法）和"修改字符串常量内容"（不合法）

### 五、结构体

#### 错题 22：指针访问成员 `->`
- **用户答案**：D（`*p.x`）
- **正确答案**：B（`p->x`）
- **表现**：混淆了指针访问成员的语法
- **原因**：结构体指针用 `->` 访问成员，等价于 `(*p).x`。`.x` 用于结构体变量，`->` 用于指针
- **正确做法**：记住 `p->x` = `(*p).x`

#### 错题 23：结构体数组索引
- **用户答案**：B（2）
- **正确答案**：C（3）
- **表现**：混淆了 `arr[1]` 和 `arr[0]`
- **原因**：`arr[2] = {{1,2},{3,4}}`，`arr[0] = {1,2}`，`arr[1] = {3,4}`，`arr[1].a = 3`
- **正确做法**：数组下标从 0 开始，`arr[1]` 是第二个元素

### 六、程序分析

#### 错题 26：后置 ++
- **用户答案**：D（5 6）
- **正确答案**：B（6 5）
- **表现**：混淆了后置 `++` 的语义
- **原因**：`y = x++` 是后置 ++，**先用后加**。y 取 x 的旧值 5，然后 x 变成 6。输出 `6 5`
- **正确做法**：后置 `x++` = 先取值再自增；前置 `++x` = 先自增再取值

#### 错题 28：冒泡排序一趟
- **用户答案**：C（1 2 3 4）
- **正确答案**：B（3 2 1 4）
- **表现**：以为一趟冒泡就能排完
- **原因**：冒泡排序每趟只把**当前最大值**冒到最后，需要多趟才能完全有序。第一趟：{4,3,2,1} → 4 和 3 换 → {3,4,2,1} → 4 和 2 换 → {3,2,4,1} → 4 和 1 换 → {3,2,1,4}
- **正确做法**：逐对比较交换，每趟只确定一个最大元素的位置

#### 错题 30 + 询问：数组指针
- **用户答案**：B（2）
- **正确答案**：C（3）
- **表现**：混淆了 `int (*p)[2]` 的语义
- **原因**：`int (*p)[2]` 是指向"每行 2 个 int"的数组指针。`p+1` 跳一整行，`*(p+1)` = 第 1 行首地址，`*(*(p+1))` = `a[1][0]` = 3
- **正确做法**：`*(*(p+1))` = `a[1][0]` = 3（不是 `a[0][1]` = 2）

## 关键知识点总结

### 🔴 高频错误类型

1. **整数除法陷阱**（Q2）：`int/int` = `int`，先算除法再赋值，类型转换太晚了
2. **值传递 vs 地址传递**（Q11, Q15）：C 默认传值，要改原变量必须传指针
3. **后置 ++ 语义**（Q26）：`x++` 先用后加，`++x` 先加后用
4. **指针相减**（Q17）：结果是元素个数，不是字节差
5. **数组指针**（Q18, Q30）：`int (*p)[N]` 指向整行，`p+1` 跳一整行
6. **悬垂指针**（Q19）：绝不返回局部变量地址
7. **结构体访问语法**（Q22）：变量用 `.`，指针用 `->`
8. **冒泡排序过程**（Q28）：每趟只把最大值冒到最后

### 🟡 需要巩固的知识点

1. **三目运算符**：右结合，`a?b:c?d:e` → `a?b:(c?d:e)`
2. **switch fall-through**：缺 `break` 合法，会贯穿
3. **continue**：跳过本轮循环剩余部分
4. **static**：只初始化一次，值跨调用保留
5. **递归执行顺序**：递归后的代码从最底层往外执行
6. **strlen vs sizeof**：前者数字符，后者数字节
7. **多维数组内存布局**：按行连续存储
