## 详细解析

### 1. 【答案】B
- **考点**：赋值表达式与条件判断、运算符区别（`=` 与 `==`）。
- **解析**：`if (a = 0)` 中是赋值操作，先将 0 赋给 `a`，整个赋值表达式的值即为 0。在 C 语言中 0 表示假，因此 `if` 分支不成立，`b++` 不会执行，`b` 保持原值 2。最终 `a` 变为 0，`b` 为 2，输出 `0, 2`。

### 2. 【答案】B
- **考点**：`sizeof` 运算符与字符串字面量在内存中的存储、隐藏的 `\0`。
- **解析**：字符串字面量由编译器自动在末尾追加一个字符 `'\0'` 作为结束标志。`"abc\0de"` 包含字符：`'a'`, `'b'`, `'c'`, `'\0'`, `'d'`, `'e'` 以及末尾自动追加的 `'\0'`，共占用 7 个字节的连续内存。`sizeof` 计算的是对象所占内存字节数，结果为 7。（对比：`strlen` 会在遇到第一个 `'\0'` 时截断，返回 3）。

### 3. 【答案】B
- **考点**：逻辑运算符短路求值特性、逻辑表达式返回值。
- **解析**：`x = ++a || ++b && ++c;` 中，逻辑或 `||` 具有短路特性。首先计算左操作数 `++a`，`a` 先自增为 1（非 0 为真）。因为左边已为真，整个逻辑表达式已确定为真，右侧的 `++b && ++c` 被完全短路跳过不执行（`b`、`c` 保持原值）。C 语言中逻辑运算为真时表达式值为 1，因此 `x = 1`。

### 4. 【答案】A
- **考点**：指针运算、运算符优先级（解引用 `*` 与加法 `+`）。
- **解析**：
  - `p` 指向数组首元素 `a[0]`。
  - `*(p + 2)` 是指针后移 2 个元素后再解引用，相当于 `a[2]`，值为 3。
  - `*p + 2` 中 `*` 优先级高于 `+`，先解引用取 `*p` 即 `a[0]`（值为 1），再加上 2，结果为 `1 + 2 = 3`。
  - 综上两者皆为 3。

### 5. 【答案】B
- **考点**：预处理宏定义无括号时的纯文本替换陷阱。
- **解析**：宏展开是单纯的文本替换，不会自动给参数加括号。`SQR(2 + 3)` 展开为 `2 + 3 * 2 + 3`。根据算术运算符优先级，先算乘法 `3 * 2 = 6`，再从左往右相加：`2 + 6 + 3 = 11`。若要得到 25，宏定义需写为 `#define SQR(x) ((x) * (x))`。
