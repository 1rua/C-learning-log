## 核心考点分布

1. **基本概念与语法基础**：标识符命名规范、数据类型与隐式转换、运算符优先级与结合性、浮点数比较陷阱。
2. **分支与流程控制**：`if-else` 配对原则、`switch-case` 穿透机制与常量表达式、三目运算符。
3. **循环结构进阶**：`while`、`do-while` 与 `for` 循环的执行顺序差异、`break` 与 `continue` 作用域、死循环边界。
4. **函数与模块化设计**：函数声明与默认返回值类型、参数传递机制、局部与全局变量作用域、典型递归与工具函数。
5. **数组、指针与字符串**：一维/二维数组遍历、矩阵运算、字符串查找/替换/排序、指针运算与数组名本质。
6. **结构体与数据建模**：简单结构体定义、多属性排序（图书查找、通讯录排序、学生成绩处理）。
