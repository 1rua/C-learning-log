### 4-1 判断素数与程序输出结果（2分）

**题目描述：**
下列程序的输出结果为 `_______`。

```c
#include <stdio.h>
int fun3(int m);
int main(void)
{   
    int n;
    for (n = 1; n < 10; n++) 
        if (fun3(n) == 1) printf("%d ", n);                   /* %d后有1个空格 */
    return 0;
}
int fun3(int m)
{   
    int i;
    if (m == 2 || m == 3) return 1;     
    if (m < 2 || m % 2 == 0) return 0;
    for (i = 3; i < m; i = i + 2) 
        if (m % i == 0) return 0;
    return 1; 
}
```

- **正确填空输出：** `2 3 5 7 ` （注意每个数字后面带有一个空格）
- **详细解析：**
  - 函数 `fun3(int m)` 的功能是判断 `m` 是否为素数（质数）：
    - 2 和 3 直接返回 1；
    - 小于 2 以及大于 2 的偶数直接返回 0；
    - 对于大于等于 3 的奇数，从 3 开始每次递增 2 试除，若能整除则返回 0，试除完毕均不能整除则返回 1。
  - `main` 中 `n` 从 1 循环到 9（`n < 10`），其中是素数的为 2、3、5、7。
  - 格式字符串为 `"%d "`，因此输出为 `2 3 5 7 `。

### 4-2 各位数字有序性判断函数与声明填空（4分）

**题目描述：**
输入若干个正整数，判断每个数从高位到低位各位数字是否按值从小到大排列，请根据题意，将程序补充完整。

```c
{   
    int k;

    while(m) 
        if( m / 10 % 10 > k)

        else {

            k = m % 10;
        }

```

- **正确填空答案：**
  - **【空1】：** `int fun1(int m);` （函数原型声明）
  - **【空2】：** `int m` （形参列表，接收整数）
  - **【空3】：** `k = m % 10;` （初始化 `k` 为最低位个位数）
  - **【空4】：** `m = m / 10;` （去掉当前最低位，向高位推进）
- **算法核心逻辑剖析：**
  - 要求判断“从高位到低位各位数字是否从小到大排列”，即高位 $\le$ 低位，反过来等价于“从低位到高位各位数字从大到小排列”，即后一位 $\le$ 前一位；
  - `k` 保存当前位数字，初始取个位 `k = m % 10`；
  - 在循环中，`m / 10 % 10` 是当前位的高一位数字。如果高一位比当前位 `k` 还大（即高位 > 低位），则违反从小到大排列，立即 `return 0;`；
  - 否则将 `m` 右移一位 `m = m / 10;`，并更新 `k = m % 10;` 继续检查更高位。循环顺利结束则返回 1。

### 4-4 static 静态局部变量与作用域生命周期（2分）

**题目描述：**
下列程序的运行结果是 `_______`。

```c
#include <stdio.h>
int f(int x)
{  
    static int y = 1;
    x += y;  
    y++;
    return x;
}
int main(void)
{  
    int k;
    k = f(3);
    printf("%d %d
", k, f(k));               //%d和%d之间只有1个空格
    return 0;
}
```

- **正确填空输出：** `4 6`
- **详细运行轨迹追踪：**
  1. `static int y = 1;`：静态局部变量只在第一次进入函数时初始化一次，生命周期贯穿整个程序运行期，多次调用之间值保持并累加。
  2. 第 1 次调用 `f(3)`：
     - 入参 `x = 3`；
     - `y` 当前为 1；
     - `x += y` -> `x = 3 + 1 = 4`；
     - `y++` -> `y` 变为 2；
     - 返回 4。此时 `main` 中 `k = 4`。
  3. 执行 `printf("%d %d
", k, f(k));`：
     - 调用 `f(k)` 即 `f(4)`：
       - 入参 `x = 4`；
       - `y` 保持上次调用的结果，当前为 2；
       - `x += y` -> `x = 4 + 2 = 6`；
       - `y++` -> `y` 变为 3；
       - 返回 6。
     - 输出 `4 6`（中间由一个空格隔开）。
