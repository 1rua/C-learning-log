### 2-1 数值溢出与类型转换截断（2分）

**题目描述：**

C语言代码段如下：
```c++
int i = 32777;
short si = i;
int j = si;
```
执行上述代码段后，`j` 的值是


**选项列表：**

- **A.** -32777
- **B.** -32759
- **C.** 32759
- **D.** 32777

- **正确答案：** **B (-32759)**

- **深度解析：**
- `i = 32777`（十六进制为 `0x00008009`）。
- 赋值给 16 位有符号整型 `short si` 时发生溢出截断，保留低 16 位 `0x8009`。
- 最高位符号位为 1，表示负数补码：补码 `0x8009` 转换为原码，数值位取反加 1 得 `0x7FF7`（十进制 32759），故值为 `-32759`。
- 再赋值给 `int j` 发生符号扩展，值仍为 `-32759`。

- **深度解析：**

### 2-4 switch-case 穿透现象（Fall-through）（1分）

**题目描述：**

下列程序段的输出结果是 （）。   @[](1)
```
int main(void)
{ 	
      int x = 1, a = 0, b = 0;
      
      switch(x)		
      {
            case 0:   b++;
            case 1:   a++;
            case 2:   a++; b++;	
      }
      printf("a=%d,b=%d\n",a,b);		

      return 0;
}

```

A. a=2,b=1
B. a=1,b=1
C. a=1,b=0
D. a=2,b=2


**选项列表：**

- **A.** a=2,b=1
- **B.** a=1,b=1
- **C.** a=1,b=0
- **D.** a=2,b=2

- **正确答案：** **A (a=2,b=1)**

- **深度解析：**
- 初始 `x = 1, a = 0, b = 0`；
- 匹配 `case 1:`，执行 `a++`（此时 `a=1`）；
- 由于 `case 1` 后面没有 `break`，发生穿透依次执行后续语句：
  - 进入 `case 2:` 执行 `a++; b++;`（此时 `a=2, b=1`）；
  - 遇到 `break;` 结束 switch。
- 最终输出 `a=2,b=1`。

### 2-6 while 循环与 continue 行为分析（2分）

**题目描述：**

下列程序段执行后`s`值为__。@[](2)

```
int i=5, s=0;
while(i--)  
    if (i%2) continue; 
    else s+=i;
```

A. 15	
B. 10	
C. 9	
D. 6


**选项列表：**

- **A.** 15
- **B.** 10
- **C.** 9
- **D.** 6

- **正确答案：** **D (6)**

- **深度解析：**
- `while(i--)`: 后置自减，先判断 `i != 0`，再执行 `i = i - 1`。
  - 第 1 次：原 i=5（真），进入后 i 变为 4。`i%2 == 0`，走 else：`s += 4` -> `s = 4`；
  - 第 2 次：原 i=4（真），进入后 i 变为 3。`i%2 == 1`，走 if：`continue`；
  - 第 3 次：原 i=3（真），进入后 i 变为 2。`i%2 == 0`，走 else：`s += 2` -> `s = 6`；
  - 第 4 次：原 i=2（真），进入后 i 变为 1。`i%2 == 1`，走 if：`continue`；
  - 第 5 次：原 i=1（真），进入后 i 变为 0。`i%2 == 0`，走 else：`s += 0` -> `s = 6`；
  - 第 6 次：原 i=0（假），退出循环。
- 最终 `s = 6`。

### 2-9 for 循环终止条件与赋值运算陷阱（2分）

**题目描述：**

下面的这个循环的循环次数是（ ）。   @[](2)       
`for(int i=0,j=10; i=j=10; i++,j--)      `   

A. 语法错误，不能执行
B. 无限次
C. 10
D. 1


**选项列表：**

- **A.** 语法错误，不能执行
- **B.** 无限次
- **C.** 10
- **D.** 1

- **正确答案：** **B (无限次)**

- **深度解析：**
`for(int i=0,j=10; i=j=10; i++,j--)` 的中间终止条件是 `i = j = 10`（赋值表达式而非相等判断 `==`）。该赋值表达式的值恒为右操作数 `10`，在 C 语言中非 0 恒为真，因此循环条件永远成立，构成死循环，执行无限次。

### 2-10 整数溢出与死循环（2分）

**题目描述：**

对下列代码的描述:

``` C
#include "stdio.h"
int main(){
    long num=1;
    while(num++ > 0) for(long i=num; i >=0; i--)printf("i :=\n \t %ld \n" , i);
    return 0;
}
```

正确的是： @[](2)

A. 程序有编译错误，不能执行
B. 循环条件永为真，循环无限次，程序根本停不下来，打印输出无限行
C. 循环有限次，程序正常结束，打印输出有限行
D. 程序运行过程必定会出错（崩溃），结果打印输出有限行

### 2-12 函数参数值传递（按值传参）（2分）

**题目描述：**

下列程序的输出结果是（）。 @[](1)
```
fun(int a, int b, int c)
{   c = a * b;  }
int main(void)
{   
      int c;

      fun(2, 3, c);
      printf(“%d\n”, c);
	
      return 0;
}
```
A. 0
B. 1
C. 6
D. 无法确定


**选项列表：**

- **A.** 0
- **B.** 1
- **C.** 6
- **D.** 无法确定

- **正确答案：** **D (无法确定)**

- 回到 `main` 后输出 `c`，打印的依然是未初始化的局部变量的值，因此结果无法确定。

```
x = -1; 
do { 
      x = x * x; 
} while (x == 0); 
```
A. 循环体将执行一次
B. 循环体将执行两次
C. 循环体将执行无限次
D. 系统将提示有语法错误


**选项列表：**

- **A.** 循环体将执行一次
- **B.** 循环体将执行两次
- **C.** 循环体将执行无限次
- **D.** 系统将提示有语法错误

- **正确答案：** **A (循环体将执行一次)**

- **深度解析：**
- 初始 `x = -1`；
- 执行循环体：`x = x * x` -> `x = (-1) * (-1) = 1`；
- 检查循环条件：`while (x == 0)`，此时 `1 == 0` 为假（0），立即退出循环。
- 循环体总共执行了 1 次。

### 2-21 循环累加的代数等价性（1分）

**题目描述：**

假设变量s、a、b、c均已定义为整型变量，且a、c均已赋值（c大于0），则与以下程序段功能等价的赋值语句是（）。   @[](1)
```
s = a;  
for(b = 1; b <= c; b++) 
      s = s + 1; 
```
A. s = a + b;
B. s = a + c;
C. s = s + c;
D. s = b + c;


**选项列表：**

- **A.** s = a + b;
- **B.** s = a + c;
- **C.** s = s + c;
- **D.** s = b + c;

- **正确答案：** **B (s = a + c;)**

- **深度解析：**
`s` 初始赋值为 `a`；循环中 `b` 从 1 变到 `c`（共循环 `c` 次），每次将 `s` 累加 1；因此循环结束后 `s` 增加了 `c`，最终 `s = a + c`。

### 2-22 辗转相减法求最大公约数（1分）

**题目描述：**

运行以下程序后，如果从键盘上输入65  14<回车>，则输出结果为（）。
```
int main(void)
{  
      int  m, n;

      printf("Enter m,n;");   
      scanf("%d%d", &m,&n);
      while (m != n)
      {   while (m > n)       m = m - n;
          while (n > m)       n = n - m;    
      }
      printf("m=%d\n",m);    

      return 0;
}
```


**选项列表：**

- **A.** m=3
- **B.** m=2
- **C.** m=1
- **D.** m=0

- **正确答案：** **C (m=1)**

- **深度解析：**
输入 `m = 65, n = 14`。程序是经典的辗转相减法（更相减损术）：
- 65 和 14：65 - 14*4 = 9 -> m=9, n=14
- 14 和 9：14 - 9 = 5 -> m=9, n=5
- 9 和 5：9 - 5 = 4 -> m=4, n=5
- 5 和 4：5 - 4 = 1 -> m=4, n=1
- 4 和 1：4 连减 1 直至相等得 `m = 1`。
本质求 65 和 14 的最大公约数，65=5*13 与 14=2*7 互质，最大公约数为 1。

### 2-23 循环中分支与 continue 打印轨迹（1分）

**题目描述：**

下列程序段的输出结果是（）。   @[](1)
```
int main(void) 
{
      for(int i = 1; i < 6; i ++) {
            if( i % 2 != 0) { 
                  printf("#");
                  continue;  
            }
      printf("*");     
      }
      printf("\n");    
     
      return 0;
}
```
A. \#\*\#\*\#
B. \#####
C. \*\*\*\*\*
D. \*\#\*\#\*


**选项列表：**

- **A.** #*#*#
- **B.** #####
- **C.** *****
- **D.** *#*#*

- **正确答案：** **A (\#\*\#\*\#)**

- **深度解析：**
`i` 从 1 遍历到 5：
- `i = 1`（奇数）：输出 `#`，执行 `continue` 跳过后续；
- `i = 2`（偶数）：走分支外输出 `*`；
- `i = 3`（奇数）：输出 `#`，`continue`；
- `i = 4`（偶数）：输出 `*`；
- `i = 5`（奇数）：输出 `#`，`continue`。
依次输出 `#*#*#`。

### 2-24 while 循环变量整除更新（1分）

**题目描述：**

执行以下程序段后，变量` i `的值是（ ）。   @[](1)
```
int i = 10;
while ( i > 3 ) {
    i /=2;
}
```
A. 1
B. 2
C. 3
D. 5


**选项列表：**

- **A.** 1
- **B.** 2
- **C.** 3
- **D.** 5

- **正确答案：** **B (2)**

- **深度解析：**
- 初始 `i = 10`；
- 第 1 次：`10 > 3` 成立，`i = 10 / 2 = 5`；
- 第 2 次：`5 > 3` 成立，`i = 5 / 2 = 2`（整数除法截断）；
- 第 3 次：`2 > 3` 不成立，退出循环。
最终 `i` 的值为 2。

### 2-25 do-while 循环步长累加（1分）

**题目描述：**

执行以下程序段后，变量`i`的值是（  ）

```
int i = 2;
do {
   i = i + 5;
} while (i < 15);
```


**选项列表：**

- **A.** 16
- **B.** 17
- **C.** 20
- **D.** 21

- **正确答案：** **B (17)**

- **深度解析：**
- 初始 `i = 2`；
- 第 1 轮：`i = 2 + 5 = 7`，`7 < 15` 为真，继续；
- 第 2 轮：`i = 7 + 5 = 12`，`12 < 15` 为真，继续；
- 第 3 轮：`i = 12 + 5 = 17`，`17 < 15` 为假，退出。
最终 `i` 的值为 17。
