### 2-1 数值溢出与类型转换截断

- **正确答案：** **B (-32759)**
- **深度考点解析：**
- `i = 32777`（十六进制为 `0x00008009`）。
- 赋值给 16 位有符号整型 `short si` 时发生溢出截断，保留低 16 位 `0x8009`。
- 最高位符号位为 1，表示负数补码：补码 `0x8009` 转换为原码，数值位取反加 1 得 `0x7FF7`（十进制 32759），故值为 `-32759`。
- 再赋值给 `int j` 发生符号扩展，值仍为 `-32759`。

### 2-2 运算符优先级

- **正确答案：** **C (%)**
- **深度考点解析：**
在 C 语言运算符优先级表中：
1. 算术运算符（`%`）优先级为 3 级（高于关系、逻辑和赋值）；
2. 关系运算符（`<=`）优先级为 6 级；
3. 逻辑与（`&&`）优先级为 11 级；
4. 赋值运算符（`=`）优先级为 14 级。
因此优先级最高的是 `%`。

### 2-3 逻辑关系表达式表示

- **正确答案：** **C (x>=10 && x<=20)**
- **深度考点解析：**
- C 语言中不支持连续关系运算写法（如 `10 <= x <= 20` 在 C 中合法但语义完全不同，会先算 `10<=x` 得 0 或 1 再与 20 比较）；
- 表示“且”的关系必须使用逻辑与运算符 `&&`，C 语言中没有保留关键字 `and`；
- 正确写法为 `x >= 10 && x <= 20`。

### 2-4 switch-case 穿透现象（Fall-through）

- **正确答案：** **A (a=2,b=1)**
- **深度考点解析：**
- 初始 `x = 1, a = 0, b = 0`；
- 匹配 `case 1:`，执行 `a++`（此时 `a=1`）；
- 由于 `case 1` 后面没有 `break`，发生穿透依次执行后续语句：
  - 进入 `case 2:` 执行 `a++; b++;`（此时 `a=2, b=1`）；
  - 遇到 `break;` 结束 switch。
- 最终输出 `a=2,b=1`。

### 2-5 if-else 就近匹配原则

- **正确答案：** **C (和之前与其最近的且不带else的if配对)**
- **深度考点解析：**
C 语言语法规则明确规定：`else` 总是与前面最近的尚未配对的 `if` 相结合配对，不受代码缩进格式影响（悬挂 else 问题，Dangling Else）。

### 2-6 while 循环与 continue 行为分析

- **正确答案：** **D (6)**
- **深度考点解析：**
- `while(i--)`: 后置自减，先判断 `i != 0`，再执行 `i = i - 1`。
  - 第 1 次：原 i=5（真），进入后 i 变为 4。`i%2 == 0`，走 else：`s += 4` -> `s = 4`；
  - 第 2 次：原 i=4（真），进入后 i 变为 3。`i%2 == 1`，走 if：`continue`；
  - 第 3 次：原 i=3（真），进入后 i 变为 2。`i%2 == 0`，走 else：`s += 2` -> `s = 6`；
  - 第 4 次：原 i=2（真），进入后 i 变为 1。`i%2 == 1`，走 if：`continue`；
  - 第 5 次：原 i=1（真），进入后 i 变为 0。`i%2 == 0`，走 else：`s += 0` -> `s = 6`；
  - 第 6 次：原 i=0（假），退出循环。
- 最终 `s = 6`。

### 2-7 嵌套循环与乘法表输出格式

- **正确答案：** **B**
- **深度考点解析：**
- 外层 `i` 从 1 到 3；
- 内层 `j` 从 `i` 开始递增到 3：
  - `i=1` 时，`j` 取 1, 2, 3，输出 `1*1=1  1*2=2  1*3=3`；
  - `i=2` 时，`j` 取 2, 3，输出 `2*2=4  2*3=6`；
  - `i=3` 时，`j` 取 3，输出 `3*3=9`。
- 与选项 B 的右上三角乘法表完全吻合。

### 2-8 循环控制 continue 语句

- **正确答案：** **C (continue)**
- **深度考点解析：**
题目要求计算能被 3 整除的整数之和。若 `i % 3 != 0`（即 `if (i % 3)` 判定为真），说明此时的 `i` 不能被 3 整除，应当跳过当前的累加操作，进入下一次循环。跳过本次循环剩余语句应使用 `continue`。

### 2-9 for 循环终止条件与赋值运算陷阱

- **正确答案：** **B (无限次)**
- **深度考点解析：**
`for(int i=0,j=10; i=j=10; i++,j--)` 的中间终止条件是 `i = j = 10`（赋值表达式而非相等判断 `==`）。该赋值表达式的值恒为右操作数 `10`，在 C 语言中非 0 恒为真，因此循环条件永远成立，构成死循环，执行无限次。

---

### 2-10 整数溢出与死循环

- **正确答案：** **B (循环条件永为真，循环无限次，程序根本停不下来，打印输出无限行)**
- **深度考点解析：**
`num` 初始为 1，外层 `while(num++ > 0)` 中，`num` 持续自增为正数；即使增加到 `LONG_MAX` 后溢出产生未定义行为/符号回转，内层循环也会每次递减打印极其庞大的输出量，外层永不会在有限步内正常结束，故无限次打印无法停下。

### 2-11 传统 C 语言函数的缺省返回类型

- **正确答案：** **D (int)**
- **深度考点解析：**
在 C89/C90 标准中，如果函数定义或声明未显式指明返回值类型，C 语言编译器默认其返回类型为 `int`。虽然现代 C99/C11 已经弃用了隐式 int（implicit-int），但在教学和考研、期末经典题目中均认定缺省为 `int`。

### 2-12 函数参数值传递（按值传参）

- **正确答案：** **D (无法确定)**
- **深度考点解析：**
- `main` 函数中的局部变量 `int c` 声明后未初始化，其初始值是不确定的垃圾值；
- 调用 `fun(2, 3, c)` 时是值传递，`fun` 函数内部修改的是自己形参 `c` 的副本，完全无法影响 `main` 函数中的局部变量 `c`；
- 回到 `main` 后输出 `c`，打印的依然是未初始化的局部变量的值，因此结果无法确定。

### 2-13 模块化程序设计与函数目的

- **正确答案：** **B (提高程序的可读性)**
- **深度考点解析：**
自定义函数将复杂程序分解为独立的逻辑模块，核心目的是提高程序的可读性、可维护性和代码复用性；函数调用存在入栈出栈开销，通常不会提高执行效率，也不会减少编译后文件所占内存。

### 2-15 形参与实参的区别

- **正确答案：** **C (形参可以是常量、变量或表达式)**
- **深度考点解析：**
形参（形式参数）在函数定义时本质上是变量，用于接收外界传入的数据，必须是具有内存存储空间的变量名，绝对不能是常量或表达式。因此选项 C 叙述错误。

### 2-16 形参与实参的内存分配

- **正确答案：** **B (实参与其对应的形参各占用独立的存储单元)**
- **深度考点解析：**
在 C 语言按值传递机制下，形参是在函数被调用时在栈区临时分配的独立存储单元，实参和形参各自拥有完全独立的内存地址空间。即便同名，它们的作用域也不同，互不干扰。

### 2-17 while 与 do-while 核心区别

- **正确答案：** **A (do-while的循环体至少无条件执行一次)**
- **深度考点解析：**
`while` 循环是“先判断后执行”，若初次条件为假则循环体一次也不执行；而 `do-while` 循环是“先执行后判断”，无论条件真假，循环体都至少无条件执行一次。

### 2-18 break 语句的作用范围

- **正确答案：** **C (break 语句只能用在循环体内和 switch 语句体内)**
- **深度考点解析：**
- A 错：`break` 也广泛用于跳出各种循环；
- B 错：`continue` 只跳过本次循环，不跳出循环；
- D 错：`break` 终止循环，`continue` 结束本次迭代；
- C 正确：`break` 语法上只能出现在循环（for/while/do-while）或 `switch` 内部。

### 2-19 do-while 循环结束判定

- **正确答案：** **D (用do-while语句构成的循环，在while后的表达式为零时结束循环)**
- **深度考点解析：**
C 语言中所有条件控制均遵循“非 0 为真，0 为假”。当 `while(expr)` 中的表达式求值为 0（假）时结束循环。

### 2-20 do-while 循环执行次数分析

- **正确答案：** **A (循环体将执行一次)**
- **深度考点解析：**
- 初始 `x = -1`；
- 执行循环体：`x = x * x` -> `x = (-1) * (-1) = 1`；
- 检查循环条件：`while (x == 0)`，此时 `1 == 0` 为假（0），立即退出循环。
- 循环体总共执行了 1 次。

### 2-21 循环累加的代数等价性

- **正确答案：** **B (s = a + c;)**
- **深度考点解析：**
`s` 初始赋值为 `a`；循环中 `b` 从 1 变到 `c`（共循环 `c` 次），每次将 `s` 累加 1；因此循环结束后 `s` 增加了 `c`，最终 `s = a + c`。

### 2-22 辗转相减法求最大公约数

- **正确答案：** **C (m=1)**
- **深度考点解析：**
输入 `m = 65, n = 14`。程序是经典的辗转相减法（更相减损术）：
- 65 和 14：65 - 14*4 = 9 -> m=9, n=14
- 14 和 9：14 - 9 = 5 -> m=9, n=5
- 9 和 5：9 - 5 = 4 -> m=4, n=5
- 5 和 4：5 - 4 = 1 -> m=4, n=1
- 4 和 1：4 连减 1 直至相等得 `m = 1`。
本质求 65 和 14 的最大公约数，65=5*13 与 14=2*7 互质，最大公约数为 1。

### 2-23 循环中分支与 continue 打印轨迹

- **正确答案：** **A (#*#*#)**
- **深度考点解析：**
`i` 从 1 遍历到 5：
- `i = 1`（奇数）：输出 `#`，执行 `continue` 跳过后续；
- `i = 2`（偶数）：走分支外输出 `*`；
- `i = 3`（奇数）：输出 `#`，`continue`；
- `i = 4`（偶数）：输出 `*`；
- `i = 5`（奇数）：输出 `#`，`continue`。
依次输出 `#*#*#`。

### 2-24 while 循环变量整除更新

- **正确答案：** **B (2)**
- **深度考点解析：**
- 初始 `i = 10`；
- 第 1 次：`10 > 3` 成立，`i = 10 / 2 = 5`；
- 第 2 次：`5 > 3` 成立，`i = 5 / 2 = 2`（整数除法截断）；
- 第 3 次：`2 > 3` 不成立，退出循环。
最终 `i` 的值为 2。

### 2-25 do-while 循环步长累加

- **正确答案：** **B (17)**
- **深度考点解析：**
- 初始 `i = 2`；
- 第 1 轮：`i = 2 + 5 = 7`，`7 < 15` 为真，继续；
- 第 2 轮：`i = 7 + 5 = 12`，`12 < 15` 为真，继续；
- 第 3 轮：`i = 12 + 5 = 17`，`17 < 15` 为假，退出。
最终 `i` 的值为 17。
