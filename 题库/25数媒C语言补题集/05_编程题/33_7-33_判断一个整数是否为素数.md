## 题目描述

本题要求编写程序，判断一个给定的整数是否为素数。素数就是只能被1和自身整除的正整数，1不是素数，2是素数。

### 输入格式:

输入在一行中给出一个需要判断的整数 $$M$$（$$ -2^{31}\le M\le 2^{31}-1$$）。

### 输出格式:

如果$$M$$是素数，则在一行中输出`Yes`，否则输出`No`。如果输入了非正整数，也要输出`No`。

### 输入样例1:
```in
11
```
### 输出样例1:
```out
Yes
```

### 输入样例2:
```in
9
```
### 输出样例2:
```out
No
```

### 输入样例3:
```in
-2
```
### 输出样例3:
```out
No
```
