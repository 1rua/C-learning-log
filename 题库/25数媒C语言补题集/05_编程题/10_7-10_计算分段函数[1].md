## 题目描述

本题目要求计算下列分段函数$$f(x)$$的值：

![公式](~/1)

### 输入格式:

输入在一行中给出实数x。

### 输出格式:

在一行中按“f(x) = result”的格式输出，其中x与result都保留一位小数。

### 输入样例1:
```in
10
```

### 输出样例1:
```out
f(10.0) = 0.1
```

### 输入样例2:
```
0
```

### 输出样例2:
```
f(0.0) = 0.0
```
