## 题目描述

本题要求编写程序，对于给定的整数$$N$$，求它的位数。

### 输入格式:

输入在一行中给出一个绝对值不超过$$10^9$$的整数$$N$$。

### 输出格式:

在一行中输出$$N$$的位数。

### 输入样例1:
```in
12534
```
### 输出样例1:
```out
5
```

### 输入样例2:
```in
-987600321
```
### 输出样例2:
```out
9
```

### 输入样例3:
```in
0
```
### 输出样例3:
```out
1
```
