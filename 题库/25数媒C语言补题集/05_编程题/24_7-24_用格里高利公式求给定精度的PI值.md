- **时间限制**：400 ms

- **代码长度限制**：16 KB
- **对应仓库状态**：⏳ 待补充/练习

## 题目描述

本题要求编写程序，计算序列部分和 $$4*(1 - 1/3 + 1/5 - 1/7 + ...)$$ ，直到最后一项的绝对值小于给定精度`eps`。

### 输入格式:

输入在一行中给出一个正实数`eps`。

### 输出格式:

在一行中按照“`Pi = pi`”的格式输出部分和的值`pi`，精确到小数点后四位。题目保证输入数据和计算结果均不超过双精度范围。

### 输入样例1:

```in
0.0001
```
### 输出样例1:
```out
Pi = 3.1418
```
### 输入样例2:

```in
0.2
```
### 输出样例2:
```out
Pi = 2.8952
```
