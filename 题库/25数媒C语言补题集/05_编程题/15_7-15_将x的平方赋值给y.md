## 题目描述

假设$$x$$的值为3，计算$$x$$的平方并赋值给$$y$$，分别以“$$y$$ = $$x$$ $$*$$ $$x$$”和“$$x$$ $$*$$ $$x$$ = $$y$$”的形式输出$$x$$和$$y$$的值。

### 输入格式：

本题无输入

### 输出格式：

按照下列格式输出代入`x`=3的结果：
```
y = x * x
x * x = y
```
