# 7-68 输出所有大于平均值的数（15分）

- **题目集**：25数媒C语言补题集
- **题目类型**：PROGRAMMING（编程题）
- **分值**：15 分
- **时间限制**：400 ms
- **内存限制**：64 MB
- **代码长度限制**：16 KB
- **对应仓库状态**：⏳ 待补充/练习

---

## 题目描述

本题要求编写程序，将输入的$$n$$个整数存入数组$$a$$中，然后计算这些数的平均值，再输出所有大于平均值的数。

### 输入格式:

输入在第1行中给出一个正整数$$n$$（$$1\le n\le 10$$），第2行输入$$n$$个整数，其间以空格分隔。题目保证数据不超过长整型整数的范围。

### 输出格式:

输出在第1行给出平均值，保留2位小数。在第2行输出所有大于平均值的数，每个数的后面有一个空格；如果没有满足条件的数，则输出空行。

如果输入的n不在有效范围内，则在一行中输出"Invalid."。

### 输入样例1:
```in
10
55 23 8 11 22 89 0 -1 78 186
```

### 输出样例1:
```out
47.10
55 89 78 186 
```

### 输入样例2:
```
0
```

### 输出样例2:
```
Invalid.
```
