## 一、数据类型、运算符与表达式

### 1-1 逗号表达式计算
**题目：** 请读程序：
```c
#include <stdio.h>
int main() {
    int a = 4, b = 7;
    printf("%d\n", (a = a + 1, b + a, b + 1));
    return 0;
}
```
输出结果是（ ）。  
A. 5  
B. 4  
C. 13  
D. 8  

- **正确答案：** D  
- **解析：** 逗号表达式 `(expr1, expr2, ..., exprN)` 依次从左到右执行，整个表达式的值取最后一个子表达式的值。先执行 `a = a + 1` 得 `a = 5`；再计算 `b + a` 为 12（但未赋值）；最后计算 `b + 1` 为 8。故结果为 8。

---

### 1-2 整数除法与类型转换
**题目：** 若有定义 `int n; float f = 13.8;`，则执行 `n = (int)f % 3;` 后，n 的值是（ ）。  
A. 1  
B. 4  
C. 4.333333  
D. 4.6  

- **正确答案：** A  
- **解析：** `(int)f` 强制将 13.8 截断小数部分取整为 13；求余运算符 `%` 要求两边均为整型，`13 % 3 = 1`。

---

### 1-3 逻辑表达式短路与优先级
**题目：** 若有定义 `int a = 5, b = 2, c = 1;`，则表达式 `a - b < c || b == c` 的值是（ ）。  
A. 0  
B. 1  
C. 2  
D. -1  

- **正确答案：** A  
- **解析：** 运算符优先级：算术运算符 `-` > 关系运算符 `<`、`==` > 逻辑或 `||`。`a - b` 得 3；`3 < 1` 为假（0）；`b == c`（`2 == 1`）为假（0）；`0 || 0` 结果为 0。

---

### 1-4 浮点数比较陷阱
**题目：** 变量 `a` 和 `b` 为 `double` 型，以下判断 `a` 与 `b` 数值相等的最恰当写法是（ ）。  
A. `a == b`  
B. `a = b`  
C. `(a - b >= -1e-6) && (a - b <= 1e-6)`  
D. `a - b == 0`  

- **正确答案：** C  
- **解析：** 浮点数在计算机中存在精度截断误差，直接使用 `==` 判断可能因微小舍入误差导致判定失败，工程和标准规范均采用绝对误差范围判断 `fabs(a - b) <= EPSILON`。

---

### 1-5 自增运算符结合性
**题目：** 若变量已正确定义并赋值，表达式 `-k++` 等价于（ ）。  
A. `-(k++)`  
B. `-(k+1)`  
C. `-(++k)`  
D. `(-k)++`  

- **正确答案：** A  
- **解析：** 后缀自增 `++` 的优先级高于单目负号 `-`，因此先与 `k` 结合为 `k++`，再取负号，即 `-(k++)`。注意：后缀自增返回的是自增前的值。

---

### 1-6 整数除法截断
**题目：** 设整型变量 `a = 2;`，则执行下列语句后，浮点型变量 `b` 的值不为 0.5 的是（ ）。  
A. `b = 1.0 / a;`  
B. `b = (float)(1 / a);`  
C. `b = 1 / (float)a;`  
D. `b = 1 / (a * 1.0);`  

- **正确答案：** B  
- **解析：** 选项 B 中括号内 `1 / a` 是两个整型相除，结果直接截断为 0，再强制转换为 float 仍为 0.0。A、C、D 均包含浮点操作数，触发浮点除法得到 0.5。

## 二、流程控制结构（分支与循环）

### 2-1 嵌套循环边界与跳转
**题目：** 执行下面的程序后，b 值为（ ）。
```c
#include <stdio.h>
int main() {
    int a, b;
    for (a = 1, b = 1; a <= 10; a++) {
        if (b >= 5)
            break;
        if (b % 3 == 1) {
            b += 3;
            continue;
        }
        b -= 5;
    }
    printf("%d", b);
    return 0;
}
```
A. 7  
B. 8  
C. 9  
D. 10  

- **正确答案：** A  
- **解析：** 跟踪循环执行过程：
  - a=1: b=1，`b%3==1` 成立，`b` 变为 4，执行 `continue`。
  - a=2: b=4，`b%3==1` 成立，`b` 变为 7，执行 `continue`。
  - a=3: b=7，满足 `b >= 5`，触发 `break` 跳出整个循环。
  - 最终输出 `b = 7`。

---

### 2-2 空循环体的结束条件
**题目：** 执行语句 `for (i = 1; i < 4; i++);` 后变量 `i` 的值是（ ）。  
A. 3  
B. 5  
C. 4  
D. 不定  

- **正确答案：** C  
- **解析：** 注意 `for` 语句末尾有分号，循环体为空语句。循环进行：i=1(<4), i=2(<4), i=3(<4)，每次步进 `i++`；当 i 增至 4 时，条件 `4 < 4` 为假退出循环，因此循环结束后 `i = 4`。

---

### 2-3 while 循环与 continue 陷阱
**题目：** 下面程序段中 while 循环的循环次数是（ ）。
```c
int i = 0;
while (i < 10) {
    if (i < 1)
        continue;
    if (i == 5)
        break;
    i++;
}
```
A. 1  
B. 10  
C. 6  
D. 死循环，不能确定次数  

- **正确答案：** D  
- **解析：** 初始 `i = 0`，满足 `i < 10` 进入循环；由于 `i < 1` 成立，执行 `continue` 立即跳过循环体剩余语句（包括 `i++`），导致 `i` 始终保持 0，陷入无限死循环。

---

### 2-4 switch-case 穿透
**题目：** 若有代码：
```c
int k = 2, s = 0;
switch (k) {
    case 1: s += 1;
    case 2: s += 2;
    case 3: s += 3;
}
printf("%d", s);
```
输出结果是（ ）。  
A. 2  
B. 3  
C. 5  
D. 编译错误  

- **正确答案：** C  
- **解析：** `k = 2` 匹配 `case 2:`，执行 `s += 2`（s 变为 2）；因为该 case 后面没有 `break`，发生穿透继续执行 `case 3:`，执行 `s += 3`（s 变为 5）。

## 三、数组与字符串处理

### 3-1 数组初始化语法合规性
**题目：** 以下能对一维数组 a 进行正确初始化的语句是（ ）。  
A. `int a[10] = (0,0,0,0,0);`  
B. `int a[2] = {0, 1, 2};`  
C. `int a[] = {0};`  
D. `int a[];`  

- **正确答案：** C  
- **解析：** 
  - A 使用了圆括号而非大括号；
  - B 初始化列表元素个数（3个）超过了数组定义长度（2个）；
  - D 省略了长度且没有初始化列表，编译器无法推断占用空间大小；
  - C 省略长度但提供了初始化列表，编译器分配 1 个元素空间，语法合法。

---

### 3-2 字符数组与字符串整体赋值
**题目：** 下述对 C 语言字符数组的描述中错误的是（ ）。  
A. 字符数组可以存放字符串  
B. 字符数组中的字符串可以整体输入、输出  
C. 可以在赋值语句中通过赋值运算符 "=" 对字符数组整体赋值  
D. 不可以用关系运算符直接对字符数组中的字符串进行比较  

- **正确答案：** C  
- **解析：** 字符数组名是地址常量（左值不可修改），定义后不能通过 `s = "hello"` 直接赋值，必须使用 `strcpy(s, "hello")` 或逐字符赋值。

---

### 3-3 strlen 与 sizeof 的本质区别
**题目：** 对于定义 `char str[] = "abc\0def";`，求 `strlen(str)` 和 `sizeof(str)` 的结果分别是（ ）。  
A. 7，8  
B. 7，7  
C. 3，8  
D. 3，7  

- **正确答案：** C  
- **解析：** 
  - `strlen` 是函数，从首地址开始数字符，遇到第一个 `\0` 立即停止计数，`"abc"` 长度为 3；
  - `sizeof` 是运算符，计算整个数组在内存中占用的物理字节总数：`'a','b','c','\0','d','e','f','\0'` 共 8 个字节。

---

### 3-4 字符串拼接覆盖行为
**题目：** 执行以下语句后，字符串 str 的值是（ ）。
```c
char str[50];
strcpy(str, "abcdefghijk");
strcpy(str + 4, "mn");
strcat(str, "xyz");
```
A. xyz  
B. abcdefghijkmnxyz  
C. mnxyz  
D. abcdmnxyz  

- **正确答案：** D  
- **解析：** 
  1. `strcpy(str, "abcdefghijk")` 使 `str = "abcdefghijk\0"`；
  2. `strcpy(str + 4, "mn")` 从下标 4（字符 `'e'` 处）开始复制 `"mn\0"`，此时 `str` 内容变为 `"abcdmn\0hijk\0"`；
  3. `strcat(str, "xyz")` 从第一个 `\0` 处开始追加 `"xyz\0"`，因此得到 `"abcdmnxyz\0"`。

## 四、函数与变量作用域/存储类型

### 4-1 值传递与形参改变
**题目：** 执行以下程序：
```c
void fun(int *p) {
    (*p)++;
}
int main() {
    int a = 5;
    fun(&a);
    printf("%d", a);
    return 0;
}
```
输出结果是（ ）。  
A. 5  
B. 6  
C. a  
D. 编译报错  

- **正确答案：** B  
- **解析：** `fun(&a)` 传入变量 `a` 的内存地址，函数内部通过解引用 `(*p)++` 直接修改了地址上的存储单元内容，因此实参 `a` 的值变为 6。

---

### 4-2 static 静态局部变量
**题目：** 下列程序的输出结果是（ ）。
```c
int f() {
    static int n = 0;
    return ++n;
}
int main() {
    printf("%d ", f());
    printf("%d ", f());
    printf("%d", f());
    return 0;
}
```
输出是（ ）。  
A. 1 1 1  
B. 1 2 3  
C. 0 1 2  
D. 3 3 3  

- **正确答案：** B  
- **解析：** `static` 静态局部变量分配在静态存储区，生命周期贯穿程序运行始终，初始化仅在首次进入时执行一次。每次调用函数 `f()`，`n` 都在上一次的值基础上自增，故依次返回 1, 2, 3。

---

### 4-3 宏替换本质
**题目：** C 语言中，编译预处理后，所有的符号常量名和宏名都用（ ）替换。  
A. 相应的字符串  
B. 相应的数值  
C. 函数调用  
D. 变量地址  

- **正确答案：** A  
- **解析：** 预处理器在编译前进行纯粹的文本替换（字符串展开），不进行任何语法和类型检查，所有宏名和宏体都按字符串形式直接替换。

## 五、指针基础与进阶运算

### 5-1 指针变量赋值语法
**题目：** 若定义 pf 为指向 float 类型变量 f 的指针，下列语句中正确的是（ ）。  
A. `float f, *pf = f;`  
B. `float f, *pf = &f;`  
C. `float *pf = &f, f;`  
D. `float f, *pf = 0.0;`  

- **正确答案：** B  
- **解析：** 指针变量必须存储变量的地址值，通过取地址符 `&f` 获得。选项 C 中定义 `*pf = &f` 时 `f` 尚未声明（编译器报错）。

---

### 5-2 指针不能进行的运算
**题目：** 在基类型相同的两个指针变量之间，不能进行的运算是（ ）。  
A. `<`  
B. `=`  
C. `+`  
D. `-`  

- **正确答案：** C  
- **解析：** 两个指针可以比较大小（判断先后顺序）、赋值、相减（求两个指针之间的元素间隔个数），但两个地址相加无物理意义且可能造成地址非法越界，语法严格禁止两个指针相加。

---

### 5-3 数组指针 vs 指针数组
**题目：** 根据声明 `int (*p)[10];`，p 是一个（ ）。  
A. 拥有 10 个整型元素的数组  
B. 指向含有 10 个整型元素的一维数组的指针  
C. 返回值为指针的函数  
D. 元素类型为指针的数组  

- **正确答案：** B  
- **解析：** `()` 优先级高于 `[]`，`(*p)` 表明 `p` 首先是一个指针，后接 `[10]` 表示指向长度为 10 的整型一维数组（行指针/数组指针）。若没有括号写成 `int *p[10];` 则为指针数组。

---

### 5-4 数组名与指针的自增合法性
**题目：** 根据声明 `int a[10], *p = a;`，下列表达式错误的是（ ）。  
A. `a[9]`  
B. `p[5]`  
C. `a++`  
D. `*p++`  

- **正确答案：** C  
- **解析：** 数组名 `a` 是一个地址常量，代表数组首元素的固定物理地址，不可作为左值修改，因此不能执行自增 `a++`；而指针 `p` 是变量，可以自由执行 `p++`。

---

### 5-5 二级指针与解引用
**题目：** 下面程序的运行结果是（ ）。
```c
#include <stdio.h>
int main(void) {
    int x[5] = {2, 4, 6, 8, 10}, *p, **pp;
    p = x;
    pp = &p;
    printf("%d ", *(p++));
    printf("%d\n", **pp);
    return 0;
}
```
A. 4 4  
B. 2 4  
C. 2 2  
D. 4 6  

- **正确答案：** B  
- **解析：** 
  1. `p` 指向 `x[0]`（值为 2）；
  2. `*(p++)`：先取 `*p` 的值即 2 打印，随后 `p` 自增指向 `x[1]`（值为 4）；
  3. `pp` 始终是指向指针变量 `p` 的二级指针，`**pp` 即解引用获得当前 `*p` 的值，此时为 4。
  4. 最终输出 `2 4`。

## 六、结构体与构造类型

### 6-1 结构体成员输入与取地址
**题目：** 有如下定义：
```c
struct pupil {
    char name[20];
    int age;
    int sex;
} pup[5], *p = pup;
```
以下 `scanf` 函数调用语句中不正确的是（ ）。  
A. `scanf("%s", pup[0].name);`  
B. `scanf("%d", &pup[0].age);`  
C. `scanf("%d", p->age);`  
D. `scanf("%d", &(p->sex));`  

- **正确答案：** C  
- **解析：** `scanf` 读取普通基本类型必须传递变量的内存地址。`p->age` 是一个 `int` 数值而非地址，必须加上取地址符 `&(p->age)` 才是合法输入。`pup[0].name` 本身是字符数组名，代表首地址，无需再加 `&`。

---

### 6-2 结构体数组整体访问错误
**题目：** 有如下定义：
```c
struct Student {
    char name[10];
    int age;
    char gender;
} std[3], *p = std;
```
则以下输入语句中错误的是（ ）。  
A. `scanf("%d", &(*p).age);`  
B. `scanf("%c", &std[0].gender);`  
C. `scanf("%c", &(p->gender));`  
D. `scanf("%s", &std.name);`  

- **正确答案：** D  
- **解析：** `std` 是结构体数组，不是单独的结构体变量，必须使用下标 `std[i].name` 引用其具体元素的成员，不能用数组名直接通过点运算符 `.name` 访问。

---

### 6-3 结构体内存分配本质
**题目：** 下列关于结构体的描述正确的是（ ）。  
A. 结构体类型本身占用内存空间，结构体变量不占用  
B. 结构体类型本身不占用内存空间，结构体变量占用内存空间  
C. 结构体成员的类型必须是基本数据类型，不能嵌套定义  
D. 可以用关系运算符直接比较两个结构体变量（如 `s1 == s2`）  

- **正确答案：** B  
- **解析：** 
  - 结构体类型的声明只是向编译器描述了一种自定义的数据组织蓝图，并不分配实际内存，只有定义了具体的结构体变量时才会为其在内存中分配空间；
  - 结构体允许嵌套包含其他结构体类型；
  - C 语言不支持结构体变量之间的直接关系运算（`==`, `!=`），必须逐个成员比较。
