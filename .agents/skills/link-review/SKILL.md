# 链接复盘

当用户发送「链接复盘」「关联复盘」「link」「建立链接」等关键词时，扫描所有复盘文件，自动建立知识点和错误的相互链接。

## 触发关键词

- 链接复盘
- 关联复盘
- link
- 建立链接

## 执行流程

### 1. 扫描所有复盘文件

1. 扫描项目文件夹中所有 `*-复盘.md` 文件
2. 读取每个复盘文件的内容，提取：
   - **本题考点** 中的知识点列表
   - **错误记录** 中的错误类型和原因
   - **关键知识点总结** 中的核心概念
   - **相关复盘** 中已有的链接（避免重复）

### 2. 匹配关联内容

将每个复盘与其他所有复盘进行比对，找出：

- **相同知识点**：两个复盘都涉及同一 C 语言概念（如 `整数除法`、`for 循环`、`scanf 格式控制`）
- **相似错误**：两个复盘记录了同类型错误（如 `变量未初始化`、`printf 格式符错误`、`循环边界错误`）
- **递进关系**：一个题目是另一个题目的延伸或变体（如从 `求N分之一序列` 到 `求交错序列`）

### 3. 建立相互链接

对每个复盘文件，在其 **"相关复盘"** 章节中：

1. **添加缺失的链接**：如果某个相关复盘尚未链接，则添加
2. **更新反向链接**：在已关联的复盘文件中追加反向链接
3. **分类整理**：按 "相同知识点"、"相似错误"、"递进练习" 分类

链接格式：

```md
## 相关复盘

### 相同知识点
- [练习2-12 输出华氏-摄氏温度转换表 - 复盘](相对路径/练习2-12-复盘.md) — 同样涉及 `整数除法` 陷阱

### 相似错误
- [练习2-13 求N分之一序列前N项和 - 复盘](相对路径/练习2-13-复盘.md) — 同样犯了 `整数除法导致精度丢失`

### 递进练习
- [练习2-14 求奇数分之一序列前N项和 - 复盘](相对路径/练习2-14-复盘.md) — 在 `求N分之一序列` 基础上增加奇数分母
```

> **链接格式**：使用 Markdown 相对路径链接 `[显示文本](相对路径)`，确保在 VS Code 中可点击跳转。
> **路径规则**：相对路径从当前复盘文件所在目录计算。

### 4. 链接原则

- **精准匹配**：只关联真正相关的内容，不要强行关联
- **双向链接**：两个相关复盘都要互相引用
- **分类清晰**：按 "相同知识点"、"相似错误"、"递进练习" 分类
- **说明原因**：每个链接后简要说明关联原因
- **避免重复**：检查是否已有相同链接，避免重复添加
- **如无则不写**：如果没有找到相关复盘，跳过此步骤

### 5. 完成反馈

链接建立完成后，应向用户报告：
- 扫描了多少个复盘文件
- 建立了多少组链接
- 发现的主要知识点关联（如 "整数除法" 出现在 X 个复盘中）
- 建议查看的关联路径
