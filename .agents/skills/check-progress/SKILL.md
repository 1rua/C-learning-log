# 检查学习进度

当用户发送「检查进度」「进度」「progress」「学习进度」等关键词时，自动扫描项目文件夹，汇总所有复盘文档、代码文件，生成一份完整的学习进度报告。

## 触发关键词

- 检查进度
- 进度
- progress
- 学习进度

## 执行流程

### 1. 自动扫描项目

1. 扫描项目根目录下的所有子文件夹
2. 收集以下学习痕迹：
   - **复盘文档**：所有 `*-复盘.md` 文件
   - **代码文件**：所有 `.c` 源文件
3. 按时间顺序（最新在前）整理学习轨迹

### 2. 分析内容

对每个复盘文档进行分析，提取：
- **题目名称**：从文件名或文档标题提取
- **完成时间**：从文件修改时间推断
- **涉及知识点**：从「本题考点」或「关键知识点总结」部分提取
- **错误记录**：从「错误记录」部分提取所有错误类型和原因
- **掌握状态**：根据复盘内容判断（已掌握 / 需巩固 / 有遗留问题）

### 4. 输出原则

- **最新内容在上**：所有时间序列都必须倒序排列，最近学的放在最前面
- **数据驱动**：所有分析必须基于实际扫描到的复盘文件和代码文件，不要编造
- **如无则跳过**：如果某个部分没有数据（如没有错误记录），直接跳过该部分，不要写"暂无"
- **知识点去重**：汇总时相同知识点合并，标注出现次数和错误次数
- **待复盘识别**：扫描到有 `.c` 代码文件但没有对应 `-复盘.md` 的题目，列为"待复盘"
- **鼓励性语气**：在报告末尾给予适当的正向反馈和学习建议

### 5. 执行步骤总结

1. 扫描项目文件夹，收集所有 `.c` 文件和 `*-复盘.md` 文件
2. 读取每个复盘文件的内容，提取知识点和错误
3. 按时间倒序整理所有学习记录
4. 生成进度报告并展示给用户
5. 更新到 `学习进度.md`
