# 检查代码

当用户发送「检查代码」「检查」「check」等关键词时，按以下流程执行。

## 触发关键词

- 检查代码
- 检查
- check

## 执行流程

### 1. 自动搜索代码文件

根据当前对话上下文中的题目名称，在项目文件夹中搜索匹配的 `.c` 文件。

搜索范围包括：
- `编程题/` 子文件夹
- `函数题/` 子文件夹
- 项目根目录
- 其他可能的子文件夹

匹配规则：文件名包含题目关键词（如题目为"输出倒三角图案"，则匹配 `*输出倒三角图案*.c`）。

### 2. 读取并分析代码

找到代码文件后：
1. 读取文件内容
2. 按照以下步骤检查：
   - 判断整体思路是否正确
   - 定位具体语法或逻辑问题
   - 解释错误原因
   - 给出最小修改方案

### 3. 检查报告格式

```md
## 代码检查结果

### 文件位置
`文件路径`

### 整体思路
整体方向是对的 / 这里思路有一点偏差。

### 发现的问题

#### 问题 1：……
- **位置**：第 X 行
- **问题**：……
- **原因**：……
- **修改建议**：……

#### 问题 2：……
- **位置**：第 X 行
- **问题**：……
- **原因**：……
- **修改建议**：……

### 下一步
你现在可以继续补上：……
```

## 检查原则

- 优先帮助用户在现有代码基础上修改，而不是重写
- 给出最小改动方案，而不是完整替换
- 解释「为什么错」，而不只是「这里错了」
- 如果代码正确，给出肯定和优化建议
