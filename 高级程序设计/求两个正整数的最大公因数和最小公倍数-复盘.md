# 求两个正整数的最大公因数和最小公倍数 - 复盘

## 题目要求

编写程序，实现两个函数：
1. `int MaxSameFactor(int a, int b)`：求两个正整数的最大公因数（GCD）。
2. `int MinCommonMultiple(int a, int b)`：求两个正整数的最小公倍数（LCM）。

题目提供了模板框架，包括全局素数数组 `pri[MAX_N]`、指数统计数组 `abpri[MAX_N]` 和素数判断函数 `IsPrime(n)`，要求基于质因数分解法（短除法）求解。

---

## 本题考点

- **素数筛选与判断**：质数的数学定义及判断边界（0 和 1 不是素数，循环从 2 开始）。
- **短除法 / 质因数分解**：
  - 提取两数的公共质因数。
  - 统计质因数的指数（重数）。
  - 合成质因数幂次乘积求得最大公约数。
- **最大公因数与最小公倍数数学关系**：
  - $\text{LCM}(a, b) = \frac{a \times b}{\text{GCD}(a, b)}$。
- **C 语言内存与变量机制**：
  - 全局数组在多次调用函数时的残留数据污染问题与数组清零（`memset` 或循环赋值）。
  - 局部变量未初始化产生的栈内存随机垃圾值。
  - 除零异常（Floating point exception / SIGFPE）在取模 `%` 中的触发。
  - 数组越界与无意义元素的遍历控制（质数实际个数控制）。

---

## 错误记录

### 逻辑错误

#### 错误 1：除以 0 导致运行时崩溃（浮点异常 Floating point exception）
- **表现**：编译通过，但运行输入数字时直接报错 `8 浮点异常（核心已转储）`。
- **原因**：
  1. `IsPrime(0)` 判定漏洞导致 0 被误判为素数，从而 `pri[0] = 0`；
  2. 后续使用 `a % pri[0]` 即 `a % 0`，触发底层 CPU 除零硬件中断；
  3. `for (n = 0; n < MAX_N; n++)` 遍历整个数组，但 10000 以内的质数只有 1229 个，数组后半部分全为 0，也会触发除零。
- **正确做法**：
  - 筛选素数严格从 `i = 2` 开始；
  - 统计实际素数个数（10000 以内为 1229 个），遍历只到实际有效素数区间，或者在 `a == 1 || b == 1` 时提前 `break`。

#### 错误 2：全局数组数据残留导致二次调用结果翻倍
- **表现**：单调 `MaxSameFactor` 正确，但在 `MinCommonMultiple` 内部第二次调用 `MaxSameFactor` 时结果错误。
- **原因**：全局数组 `abpri` 在第一次调用后留有上一次的指数计数值，未清零直接继续累加。
- **正确做法**：在每次进入计算前，清空 `abpri` 数组（通过循环或 `memset` 清零）。

#### 错误 3：最大公约数合成用了加法而非乘法
- **表现**：质因数计算出来后，求和而非求积（如 $2^3 \times 3^2 \times 7^1 = 504$，误算为 $8 + 9 + 7 = 24$）。
- **原因**：累加思想惯性，误把指数幂项用 `+` 累加。
- **正确做法**：初值设为 1，进行累乘 `gcd = gcd * pow(pri[i], abpri[i])`。

### 语法错误

#### 错误 1：局部变量 `gcd` 未赋初值
- **表现**：直接在未初始化的变量上运算，产生巨大随机数值。
- **原因**：C 语言局部变量在栈上分配，不赋初值会保留内存残留垃圾值。
- **正确做法**：定义时显式初始化为 1：`int gcd = 1;`。

## 优化与拓展

### 1. 算法对比：短除法 vs 辗转相除法（欧几里得算法）

- **质因数分解法（当前做法）**：
  - 优点：完全还原小学数学短除法的思维过程，适合深入理解数论和数组操作。
  - 缺点：需要预先打素数表，空间消耗大（开数组），且对于大质数（如大于 10000）无法处理，容易超时。
- **辗转相除法（工程与算法题标准解法）**：
  - 原理：$\gcd(a, b) = \gcd(b, a \% b)$。
  - 代码极简（无需数组，无需素数表，时间复杂度 $O(\log(\min(a, b)))$）：
    ```c
    int MaxSameFactor(int a, int b) {
        while (b != 0) {
            int r = a % b;
            a = b;
            b = r;
        }
        return a;
    }
    ```

### 2. 最小公倍数防溢出技巧
- 公式 $\text{LCM} = \frac{a \times b}{\text{GCD}}$ 中，若 $a$ 和 $b$ 较大（如各几万），$a \times b$ 可能会超出 32 位整型（`int`）的最大值 2147483647 导致整数溢出。
- **优化写法**：先除后乘 `return (a / MaxSameFactor(a, b)) * b;`。因为 $a$ 一定能被它们的最大公约数整除，先除不会丢失精度，且有效避免溢出。

## 关键知识点总结

1. **除零安全**：取模 `%` 和除法 `/` 运算必须时刻警惕除数是否可能为 0。
2. **全局变量的“副作用”**：在函数题和模块化设计中，全局变量容易在函数多次调用间互相污染，使用前必须重置或优先使用局部变量。
3. **乘积累乘初值**：累加初值为 0，累乘初值为 1。
