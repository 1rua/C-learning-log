# 练习2-18 求组合数 - 复盘

## 题目要求

根据公式 $C_n^m = \frac{n!}{m!(n-m)!}$ 计算从 n 个不同元素中取出 m 个元素的组合数。

要求定义和调用函数 `fact(n)` 计算 n!，其中 n 的类型是 int，函数类型是 double。

输入：两个正整数 m 和 n（m≤n），以空格分隔。
输出：按照格式 "result = 组合数计算结果" 输出。

## 本题考点

- 函数的定义、声明和调用
- 函数参数（形参和实参）的理解
- `double` 类型的使用和浮点数运算
- `for` 循环实现累乘
- 全局变量与局部变量的作用域区别
- 输出格式控制（`%.0f`）

## 错误记录

### 逻辑错误

#### 错误 1：`return` 语句放在循环内部
- **表现**：`fact()` 函数只返回 1，导致组合数计算结果错误
- **原因**：`return result;` 写在 `for` 循环的花括号内，第一次循环就返回了
- **正确做法**：`return` 应该放在循环结束后

```c
// 错误
for(a = 1; a <= n; a++) {
    result *= a;
    return result;  // 第一次循环就返回
}

// 正确
for(a = 1; a <= n; a++) {
    result *= a;
}
return result;  // 循环结束后返回
```

### 语法错误

#### 错误 1：`printf` 格式控制符错误
- **表现**：使用 `%d` 输出 `double` 类型变量，输出为 0 或乱码
- **原因**：`%d` 用于输出 `int` 类型，`double` 应该用 `%f` 或 `%.0f`
- **正确做法**：`printf("result = %.0f\n", c);`

#### 错误 2：函数定义参数缺少类型
- **表现**：`double fact(n){` 编译可能报错或警告
- **原因**：C 语言函数参数必须写明类型
- **正确做法**：`double fact(int n){`

#### 错误 3：`main` 函数末尾多了分号
- **表现**：`};` 不符合 C 语言语法规范
- **原因**：函数定义结尾用花括号 `}`，不需要分号
- **正确做法**：`}`

### 代码风格问题

#### 问题 1：全局变量滥用
- **表现**：循环变量 `a` 定义为全局变量
- **原因**：全局变量可能被其他函数意外修改，且不利于代码复用
- **正确做法**：将 `a` 作为 `fact` 函数的局部变量

## 优化与拓展

- 可以将组合数计算也封装成 `comb(m, n)` 函数，提高代码可读性
- 函数嵌套调用：`comb` 调用 `fact`，`main` 调用 `comb`

```c
double comb(int m, int n) {
    return fact(n) / (fact(m) * fact(n - m));
}
```

## 关键知识点总结

1. **函数声明 vs 定义**：声明告诉编译器函数存在（加分号），定义写出函数具体实现（加花括号）
2. **形参 vs 实参**：定义时写形参（类型+名字），调用时传实参（具体值或变量）
3. **return 位置**：`return` 应该在函数逻辑完成后执行，不要在循环中间提前返回
4. **格式控制符匹配**：`%d` 对应 `int`，`%f`/`%.0f` 对应 `double`
5. **局部变量优先**：循环计数器等临时变量应定义为局部变量，避免全局变量污染
