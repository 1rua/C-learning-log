# 习题2-2 阶梯电价 - 复盘

## 题目要求

计算阶梯电价：
- 月用电量 ≤ 50 千瓦时：电价为 0.53 元/千瓦时
- 月用电量 > 50 千瓦时：超出部分电价上调 0.05 元/千瓦时（即 0.58 元/千瓦时）

输入：一行，月用电量（千瓦时）
输出：若用电量 < 0，输出 `Invalid Value!`；否则输出 `cost = 应付电费值`，保留两位小数

## 本题考点

- `double` 双精度浮点数类型及输入输出（`%lf` / `%f`）
- 嵌套 `if-else` 条件判断
- 分段函数的计算逻辑
- 输出格式控制（`%.2f` 保留两位小数）
- 边界条件处理（负数输入、50 千瓦时临界点）

## 优化与拓展

### 优化建议 1：简化嵌套结构
原代码使用嵌套 `if-else`，可以改为 `if-else if-else` 结构，逻辑更清晰：

```c
if (power < 0) {
    printf("Invalid Value!\n");
} else if (power <= 50) {
    cost = 0.53 * power;
    printf("cost = %.2f\n", cost);
} else {
    cost = 0.53 * 50 + 0.58 * (power - 50);
    printf("cost = %.2f\n", cost);
}
```

### 优化建议 2：提前返回减少嵌套
```c
if (power < 0) {
    printf("Invalid Value!\n");
    return 0;  // 提前结束
}

// 下面只需要处理正常情况，减少一层嵌套
if (power <= 50) {
    cost = 0.53 * power;
} else {
    cost = 0.53 * 50 + 0.58 * (power - 50);
}
printf("cost = %.2f\n", cost);
```

### 其他实现思路
- 本题本质是**分段函数**，核心是找到"分界点"（50 千瓦时），分别处理两段
- 可以用三元运算符简写（但不建议初学者过度使用）：
  ```c
  cost = (power <= 50) ? 0.53 * power : 0.53 * 50 + 0.58 * (power - 50);
  ```

## 关键知识点总结

1. **分段函数处理**：找到分界点，用 `if-else` 分别处理不同区间
2. **浮点数精度**：电价计算涉及小数，使用 `double` 类型
4. **输出格式严格匹配**：OJ 对输出格式非常敏感，注意空格、换行、大小写
5. **边界条件**：
   - 负数输入 → 特殊处理
   - 恰好 50 千瓦时 → 属于第一档（`<= 50`）
