# 计算物体自由下落的距离 - 复盘

## 题目要求

一个物体从100米的高空自由落下。求它在前3秒内下落的垂直距离。设重力加速度为10米/秒²。

输出格式：`height = 垂直距离值`，结果保留2位小数。

## 本题考点

- 自由落体物理公式的程序实现
- 浮点数类型 `double` 的使用
- `printf` 格式控制符 `%.2f` 的用法
- 题目要求的精确理解（下落距离 vs 剩余高度）
- 不必要的库函数依赖（`pow` vs 直接乘法）

## 逻辑错误

### 错误 1：公式理解错误——计算了剩余高度而非下落距离
- **表现**：输出结果与预期不符，得到的是 `100 - 下落距离`
- **原因**：题目要求的是"前3秒内下落的垂直距离"，应直接使用自由落体公式 `h = 1/2 * g * t²`。但代码写成了 `height = a - 10 * pow(i,2)`，计算的是剩余高度
- **正确做法**：`height = 0.5 * 10 * 3 * 3;` 或 `height = 10.0 * 3 * 3 / 2;`

### 错误 2：引入了不必要的变量
- **表现**：定义了 `int a = 100;` 但没有正确利用
- **原因**：100米是初始高度，但题目只要求"下落距离"，不需要用初始高度去减。这个变量是多余的
- **正确做法**：直接根据公式计算下落距离，不需要初始高度参与运算

## 语法错误

### 错误 1：变量类型选择错误
- **表现**：`int height;` 导致小数部分被截断
- **原因**：题目要求保留2位小数，必须使用浮点型。`int` 只能存储整数，赋值时会截断小数
- **正确做法**：`double height;`

### 错误 2：printf 格式控制符错误
- **表现**：`printf("height = %d", height);`
- **原因**：`%d` 用于输出 `int` 类型，而 `height` 是浮点数。混用会导致输出乱码或不正确的值
- **正确做法**：`printf("height = %.2f\n", height);`

### 错误 3：缺少换行符
- **表现**：输出没有换行
- **原因**：虽然某些判题系统不严格要求换行，但规范输出应该加上 `\n`
- **正确做法**：在格式字符串末尾加 `\n`

## 关键知识点总结

1. **自由落体公式**：`h = 1/2 * g * t²`，注意题目问的是"下落距离"还是"剩余高度"
2. **浮点数输出**：保留2位小数用 `%.2f`
3. **类型匹配**：`printf` 的格式控制符必须和变量类型一致
4. **简化计算**：简单的平方运算直接用乘法，不必调 `pow`

## 浮点变量详解

### 声明浮点变量

C语言中常用的浮点类型有三个：

| 类型 | 占用字节 | 精度 | 使用场景 |
|------|---------|------|---------|
| `float` | 4字节 | 约6-7位有效数字 | 存储空间敏感时（如嵌入式） |
| `double` | 8字节 | 约15-16位有效数字 | **默认推荐**，精度更高 |
| `long double` | 8~16字节（平台相关） | 约18位以上有效数字 | 高精度科学计算 |

声明方式：

```c
double height;          // 声明一个双精度浮点变量
double a = 3.14;        // 声明时初始化
float x = 1.5f;         // float类型需要在数字后加 f 或 F
long double y = 1.23456789L;  // long double 加 L
```

**为什么推荐 `double`？**
- `double` 精度更高，能减少累积误差
- C语言默认的小数字面量（如 `3.14`）就是 `double` 类型
- 数学函数（如 `pow`、`sqrt`）默认接收和返回 `double`

### 三种浮点类型的区别

**`float`（单精度）**
- 32位存储：1位符号 + 8位指数 + 23位尾数
- 能表示的范围：约 ±3.4×10³⁸
- 有效数字：6~7位
- 示例：`float pi = 3.1415926f;` 实际只存了 `3.141593` 左右

**`double`（双精度）**
- 64位存储：1位符号 + 11位指数 + 52位尾数
- 能表示的范围：约 ±1.7×10³⁰⁸
- 有效数字：15~16位
- 示例：`double pi = 3.141592653589793;` 能完整存下

**`long double`（扩展精度）**
- 80位或128位存储（取决于编译器和CPU）
- 有效数字：18位以上
- 使用场景：天文计算、高精度金融、科学模拟
- 注意：不同平台实现差异大，可移植性不如 `double`

### 精度对比示例

```c
#include <stdio.h>

int main(void) {
    float f = 1.0f / 3.0f;
    double d = 1.0 / 3.0;
    long double ld = 1.0L / 3.0L;
    
    printf("float:       %.10f\n", f);   // 0.3333333433（第8位开始出错）
    printf("double:      %.20f\n", d);   // 0.33333333333333331000（第16位开始出错）
    printf("long double: %.25Lf\n", ld); // 精度更高
    
    return 0;
}
```

### 实际使用建议

| 场景 | 推荐类型 | 原因 |
|------|---------|------|
| 一般编程练习 | `double` | 默认、精度足够、不易出错 |
| 嵌入式/单片机 | `float` | 内存和计算速度敏感 |
| 高精度科学计算 | `long double` | 需要更多有效数字 |
| 金融计算 | 整数或专用库 | 浮点数有精度损失，不适合精确金额 |

**重要提醒**：
- 浮点数在计算机中都是**近似存储**，`0.1 + 0.2 != 0.3` 在浮点运算中可能成立
- 如果需要绝对精确（如金额），应该用整数（分而不是元）或专用库

### 浮点变量的输出

`printf` 输出浮点数的格式控制符：

| 格式符 | 含义 | 示例 |
|--------|------|------|
| `%f` | 默认输出6位小数 | `printf("%f", 3.14);` → `3.140000` |
| `%.2f` | 保留2位小数（四舍五入） | `printf("%.2f", 3.14159);` → `3.14` |
| `%.3f` | 保留3位小数 | `printf("%.3f", 3.14159);` → `3.142` |
| `%e` | 科学计数法 | `printf("%e", 1234.5);` → `1.234500e+03` |
| `%g` | 自动选择 `%f` 或 `%e` | 根据数值大小自动选择更短的格式 |

**常见错误**：

```c
double height = 45.0;
printf("%d", height);   // 错误！%d 输出 int，对 double 会输出乱码
printf("%f", height);   // 正确，但默认输出 6 位小数：45.000000
printf("%.2f", height); // 正确，输出 45.00
```

### 浮点变量的输入

`scanf` 读取浮点数：

```c
double height;
float x;

scanf("%lf", &height);  // double 用 %lf（注意是字母 l，不是数字 1）
scanf("%f", &x);        // float 用 %f
```

**注意**：`scanf` 读取 `double` 时必须用 `%lf`，而 `printf` 输出 `double` 时用 `%f` 或 `%.2f` 都可以。

### 整数除法的陷阱

```c
double result;

result = 1 / 2;         // 错误！两个 int 相除，结果是 0（整数除法截断小数）
result = 1.0 / 2;       // 正确！1.0 是 double，结果自动转为 0.5
result = 1 / 2.0;       // 正确！
result = (double)1 / 2; // 正确！强制类型转换
```

### 本题中的浮点应用

```c
#include <stdio.h>

int main(void) {
    double height;          // 1. 声明 double 变量
    int t = 3;
    
    height = 0.5 * 10 * t * t;  // 0.5 是 double，整个表达式自动按浮点计算
    
    printf("height = %.2f\n", height);  // 2. 用 %.2f 保留2位小数
    
    return 0;
}
```

## 整数与浮点数的混合运算

### 自动类型转换规则

C语言中，整数和浮点数可以混合运算，编译器会自动进行**类型提升**：

```c
int a = 5;
double b = 2.5;
double result;

result = a + b;      // int 自动转为 double，结果是 7.5
result = a / 2.0;    // 2.0 是 double，a 自动提升，结果是 2.5
result = a / 2;      // 两边都是 int，结果是 2（整数除法）
```

**转换规则（从低到高）**：

```
int → float → double → long double
```

运算时，低精度类型会自动提升到高精度类型，结果也是高精度类型。

### 常见陷阱

```c
int a = 5, b = 2;
double result;

result = a / b;           // 错误！结果是 2.0，不是 2.5
result = (double)a / b;   // 正确！强制转换后结果是 2.5
result = a / (double)b;   // 正确！
result = 1.0 * a / b;     // 正确！1.0 让表达式整体按浮点计算
```

### 赋值时的截断

```c
double a = 5.7;
int b;

b = a;        // 警告！double 赋值给 int，小数部分截断，b = 5
b = (int)a;   // 显式转换，明确告诉编译器"我知道会截断"
```

## 常用 math.h 函数

使用数学函数前需要包含头文件：`#include <math.h>`

### 基本运算

| 函数 | 功能 | 示例 | 结果 |
|------|------|------|------|
| `sqrt(x)` | 平方根 | `sqrt(16.0)` | `4.0` |
| `pow(x, y)` | x 的 y 次方 | `pow(2.0, 3.0)` | `8.0` |
| `fabs(x)` | 绝对值（浮点） | `fabs(-3.14)` | `3.14` |
| `fmod(x, y)` | 浮点取余 | `fmod(5.5, 2.0)` | `1.5` |

### 三角函数（弧度制）

| 函数 | 功能 | 示例 |
|------|------|------|
| `sin(x)` | 正弦 | `sin(3.14159/2)` → `1.0` |
| `cos(x)` | 余弦 | `cos(0)` → `1.0` |
| `tan(x)` | 正切 | `tan(3.14159/4)` → `1.0` |
| `asin(x)` | 反正弦 | `asin(1.0)` → `π/2` |
| `acos(x)` | 反余弦 | `acos(1.0)` → `0` |
| `atan(x)` | 反正切 | `atan(1.0)` → `π/4` |

**角度转弧度**：`弧度 = 角度 × π / 180`

```c
double degree = 90.0;
double radian = degree * 3.14159 / 180.0;
double result = sin(radian);  // sin(90°) = 1.0
```

### 指数与对数

| 函数 | 功能 | 示例 | 结果 |
|------|------|------|------|
| `exp(x)` | e 的 x 次方 | `exp(1.0)` | `2.718...` |
| `log(x)` | 自然对数（ln） | `log(2.718)` | `~1.0` |
| `log10(x)` | 常用对数（lg） | `log10(100.0)` | `2.0` |

### 取整函数

| 函数 | 功能 | 示例 | 结果 |
|------|------|------|------|
| `ceil(x)` | 向上取整 | `ceil(3.14)` | `4.0` |
| `floor(x)` | 向下取整 | `floor(3.14)` | `3.0` |
| `round(x)` | 四舍五入 | `round(3.5)` | `4.0` |

### 常量

| 常量 | 值 | 说明 |
|------|-----|------|
| `M_PI` | 3.14159... | 圆周率（部分编译器支持） |
| `M_E` | 2.71828... | 自然常数 e |

**注意**：`M_PI` 不是标准C，某些编译器需要加 `#define _USE_MATH_DEFINES`（Windows）或手动定义。

### 使用示例

```c
#include <stdio.h>
#include <math.h>

int main(void) {
    double a = 16.0, b = 3.0;
    
    printf("sqrt(16) = %.2f\n", sqrt(a));      // 4.00
    printf("pow(2, 3) = %.2f\n", pow(2.0, b)); // 8.00
    printf("fabs(-3.14) = %.2f\n", fabs(-3.14)); // 3.14
    printf("ceil(3.14) = %.2f\n", ceil(3.14));  // 4.00
    printf("floor(3.14) = %.2f\n", floor(3.14)); // 3.00
    printf("round(3.5) = %.2f\n", round(3.5));  // 4.00
    
    // 三角函数示例
    double pi = acos(-1.0);  // 用反余弦求 π
    printf("sin(90°) = %.2f\n", sin(pi / 2));   // 1.00
    
    return 0;
}
```

### 什么时候需要 math.h

| 场景 | 是否需要 |
|------|---------|
| 加减乘除、取模 `%` | ❌ 不需要 |
| 平方直接用 `x * x` | ❌ 不需要 |
| 平方根、幂运算、三角函数 | ✅ 需要 |
| 对数、指数 | ✅ 需要 |
| 浮点取整（ceil/floor/round） | ✅ 需要 |

**本题反思**：计算 `t²` 直接用 `t * t` 即可，不需要 `pow(t, 2)`，更不需要引入 `math.h`。
