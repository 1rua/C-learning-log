# 练习2-3 输出倒三角图案 - 复盘

## 题目要求

输出由"*"组成的倒三角图案：

```
* * * *
 * * *
  * *
   *
```

## 本题涉及知识点

- `for` 循环嵌套
- `printf` 格式化输出
- 空格和换行的精确控制
- 循环变量的边界控制

## 解题思路

将图案拆解为每行的两个部分：

| 行号(i) | 前导空格数 | * 的数量 |
|---------|-----------|---------|
| 0       | 0         | 4       |
| 1       | 1         | 3       |
| 2       | 2         | 2       |
| 3       | 3         | 1       |

规律：
- 外层循环控制 4 行（i 从 0 到 3）
- 第 i 行：先输出 i 个空格，再输出 4-i 个 *
- * 之间用空格分隔，但第一个 * 前面不能有空格

## 最终正确代码

```c
#include <stdio.h>

int main(void) {
    int i, j;
    for (i = 0; i < 4; i++) {
        // 输出前导空格
        for (j = 0; j < i; j++) {
            printf(" ");
        }
        // 输出 *，注意第一个 * 前面不加空格
        for (j = 0; j < 4 - i; j++) {
            if (j > 0) {
                printf(" ");  // 后面的 * 前面加空格
            }
            printf("*");
        }
        printf("\n");
    }
    return 0;
}
```

## 本次犯的错误

### 1. for 循环分隔符错误
- **错误**：`for(j = 0,j < i,j++)` 使用逗号分隔
- **正确**：`for(j = 0; j < i; j++)` 使用分号分隔
- **原因**：for 循环的三个部分（初始化、条件、增量）必须用分号分隔

### 2. 变量重复定义
- **错误**：`int i, j;` 后面又写了 `int i = 4;`
- **正确**：同一个作用域内不能重复定义同名变量
- **原因**：C 语言不允许同一作用域内重复声明变量

### 3. printf 格式错误
- **错误**：`printf(%d" *")` 缺少引号，且使用了错误的格式控制符
- **正确**：`printf("*");` 或 `printf(" ");`
- **原因**：printf 的第一个参数必须是字符串，用双引号包裹

### 4. 语句末尾缺少分号
- **错误**：`printf("\n")` 后面没有分号
- **正确**：`printf("\n");`
- **原因**：C 语言每条语句必须以分号结束

### 5. return 0 位置错误
- **错误**：`return 0;` 写在了 main 函数的花括号外面
- **正确**：`return 0;` 必须写在 main 函数内部
- **原因**：return 语句必须在函数体内执行

### 6. 循环边界错误
- **错误**：`i <= 4` 导致输出 5 行
- **正确**：`i < 4` 只输出 4 行
- **原因**：从 0 开始时，`< 4` 对应 0,1,2,3 共 4 次

### 7. 格式控制错误（最关键）
- **错误**：`printf(" *");` 每个 * 前面都有空格
- **正确**：第一个 * 前面没有空格，后面的 * 前面有空格
- **原因**：题目要求的是 `* * * *`，不是 ` * * * *`
- **PTA 特点**：PTA 对输出格式要求非常严格，多空格、少空格都会判格式错误

## 关键知识点总结

### for 循环语法
```c
for (初始化; 条件; 增量) {
    // 循环体
}
```
三个部分用分号 `;` 分隔，不是逗号。

### 循环嵌套的执行顺序
外层循环执行一次，内层循环执行完整的一轮。

### printf 输出空格
空格就是一个普通字符，直接用 `" "` 输出。

### PTA 格式要求
- 必须严格匹配题目要求的输出格式
- 空格、换行、标点都不能多不能少
- 建议先在本机运行，对比题目样例，确认完全一致后再提交
