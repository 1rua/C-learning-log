# 习题3-5 三角形判断 - 复盘

## 题目要求

给定平面上三个点的坐标，检验它们能否构成三角形。若能，输出周长和面积（保留2位小数）；若不能，输出 "Impossible"。

输入格式：一行六个 `[−100,100]` 范围内的**数字**（注意：是数字，不是整数，可能是实数）。

## 本题考点

- `scanf` 读取 `double` 类型：`%lf`（区别于 `printf` 的 `%f`）
- `sqrt()` 数学函数的使用（需 `#include <math.h>`，编译加 `-lm`）
- 两点间距离公式：`d = √((x₁-x₂)² + (y₁-y₂)²)`
- 三角形不等式判定：`a + b > c && a + c > b && b + c > a`
- 海伦公式求面积：`A = √(p(p-a)(p-b)(p-c))`，其中 `p = (a+b+c)/2`
- 浮点类型 `double` 与整数 `int` 的适用场景区分
- `printf` 格式控制：`%.2f` 保留两位小数

## 错误记录

### 逻辑错误

#### 错误 1：先算面积，后判断三角形
- **表现**：在 `if` 判断之前就计算了 `A = sqrt(P*(P-a)*(P-b)*(P-c))`
- **原因**：如果三点共线（不能构成三角形），`(P-a)`、`(P-b)`、`(P-c)` 中至少有一个 ≤ 0，乘积为负或零，`sqrt()` 对负数取平方根会产生 `NaN`
- **正确做法**：把面积和周长的计算移到 `if` 块内部，先判断再计算

### 语法错误

#### 错误 1：坐标变量类型用 `int`，只能读整数
- **表现**：测试点 2「输入为实数」答案错误
- **原因**：题目说的是「数字」而非「整数」，输入可能是 `4.5 6.2` 这样的实数。`int` 类型只能存整数，`%d` 只能读整数，读到小数点就会出错
- **正确做法**：
  ```c
  double x1, y1, x2, y2, x3, y3;           // 用 double
  scanf("%lf %lf %lf %lf %lf %lf", ...);    // 用 %lf
  ```

#### 错误 2：`scanf` 格式符 `%D` 大写
- **表现**：`scanf("%D %d ...", ...)` 
- **原因**：C 语言中 `%d` 和 `%D` 是不同的，`%D` 不是标准格式说明符
- **正确做法**：统一使用小写 `%d`

#### 错误 3：边长变量用 `int`，丢失精度
- **表现**：`int a, b, c;` 然后 `a = sqrt(...)`
- **原因**：`sqrt()` 返回 `double` 类型，赋值给 `int` 会截断小数部分。比如 `√2 ≈ 1.414` 变成 `1`，精度全丢
- **正确做法**：`double a, b, c;`

## 关键知识点总结

### 1. `scanf` 和 `printf` 对 `double` 的格式符不一致

| 函数 | `float` | `double` |
|---|---|---|
| `scanf` | `%f` | `%lf`（必须加 `l`） |
| `printf` | `%f` | `%f`（`%lf` 也行但等价于 `%f`） |

这可能是 C 语言最反直觉的设计之一：`scanf` 读 `double` 必须用 `%lf`，而 `printf` 输出 `double` 用 `%f` 就够了。

> **为什么？** 因为 `printf` 的可变参数会进行「默认参数提升」：`float` 会自动提升为 `double`，所以 `printf` 看到的永远是 `double`，`%f` 和 `%lf` 没区别。但 `scanf` 通过指针传递，没有类型提升，必须精确区分 `float*`（`%f`）和 `double*`（`%lf`）。

### 2. 输入类型要与题目描述对齐

题目说「数字」不等于「整数」。「数字」可能包含小数点，所以必须用 `double` + `%lf`。这是一个常见的 OJ 陷阱：样例给的是整数，但隐藏测试点用的是实数。

### 3. 海伦公式的记忆

```
p = (a + b + c) / 2        （半周长）
A = √(p(p-a)(p-b)(p-c))    （面积）
```

### 4. 三角形判定的正确写法

```c
if (a + b > c && a + c > b && b + c > a) {
    // 是三角形
}
```

三个条件缺一不可，且必须是**严格大于**（`>`），等于（`==`）时三点共线，不构成三角形。
