# 练习2-8 计算摄氏温度 - 复盘

## 题目要求

给定一个华氏温度 F，计算对应的摄氏温度 C。
计算公式：C = 5 × (F − 32) / 9

输入：一个华氏温度整数
输出：按照格式 "Celsius = C" 输出对应的摄氏温度整数值

---

## 本题考点

- 变量的定义与使用
- `scanf` 读取整数输入
- `printf` 格式化输出
- 基本的算术运算与整数除法
- 严格匹配题目要求的输入输出格式

---

## 语法错误

### 错误 1：`scanf` 格式控制符写错
- **表现**：写成 `scanf("&d", &fahr);`
- **原因**：把取地址符 `&` 和格式控制符 `%` 搞混了。`%d` 才是读取整数的格式说明符
- **正确做法**：`scanf("%d", &fahr);`

---

## 环境/工具问题（非课内知识点，单独分类）

### 问题 1：中文编码导致编译报错
- **表现**：代码中有中文时，编译器报 `C4819`（字符不能在当前代码页表示）、`C2001`（常量中有换行符）、`C2146`（语法错误）等
- **原因**：VS Code 默认用 UTF-8 保存文件，但 MSVC 编译器使用 GBK/GB2312（代码页 936）解析，编码不匹配导致中文字符被错误解析，破坏语法结构
- **解决方法**：在 VS Code 右下角将文件编码改为 `GB2312` 或 `GBK` 后保存
- **预防建议**：PTA 题目通常不需要中文输入提示，代码中避免使用中文可减少此类问题

### 问题 2：`LNK1168` 无法写入 .exe 文件
- **表现**：编译时报错 "无法打开 .exe 进行写入"
- **原因**：之前运行的程序窗口未关闭，.exe 文件被系统占用，编译器无法覆盖
- **解决方法**：关闭之前运行的命令行窗口，或在终端执行 `taskkill /F /IM "*.exe"`
- **预防建议**：每次重新编译前，养成关闭之前运行窗口的习惯

---

## 关键知识点总结

1. `scanf("%d", &变量)` 读取整数时，`%d` 是格式控制符，`&` 是取地址符，两者作用不同
2. `printf` 的输出格式必须严格匹配题目要求，包括大小写、空格、等号位置
3. 整数运算 `(a * b) / c` 从左到右计算，在整型范围内不会丢失精度
4. Windows 下中文编码问题（UTF-8 vs GBK）是常见坑点，遇到奇怪语法错误时优先考虑编码问题
