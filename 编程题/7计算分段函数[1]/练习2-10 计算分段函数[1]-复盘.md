# 练习2-10 计算分段函数[1] - 复盘

## 题目要求

计算分段函数 f(x) 的值：
- 当 x ≠ 0 时，f(x) = 1/x
- 当 x = 0 时，f(x) = 0

输入一个实数 x，按 "f(x) = result" 格式输出，x 与 result 都保留一位小数。

## 本题考点

- `if-else` 条件分支结构
- `double` 类型的输入输出格式控制
- `scanf` 与 `printf` 格式控制符的区别
- 浮点数运算中的类型转换（整数除法 vs 浮点数除法）
- 分段函数的程序实现思路

## 错误记录

### 语法错误

#### 错误 1：`scanf` 使用了输出格式控制符
- **表现**：输入任何数都输出 `f(0.0) = 0.0`
- **原因**：`scanf` 写成了 `scanf("%.1f", &x)`，`%.1f` 是 `printf` 的输出格式，`scanf` 不支持精度控制。导致 `x` 没有被正确读取。
- **正确做法**：`scanf` 读取 `double` 时用 `%lf`，即 `scanf("%lf", &x);`

#### 错误 2：整数除法导致计算结果错误
- **表现**：如果输入能读取，计算结果可能为 0
- **原因**：`a = 1 / x;` 中 `1` 是 `int` 类型，`x` 是 `double`，但 `1 / x` 会先按整数规则处理
- **正确做法**：写成 `a = 1.0 / x;`，让 `1.0` 作为 `double` 参与运算

#### 错误 3：`else` 后面多余分号
- **表现**：`} else {` 后面写了 `};`
- **原因**：`else` 是控制结构关键字，本身不需要分号
- **正确做法**：`else` 块结束后直接写 `}`，不加多余分号

### 逻辑错误

#### 错误 1：输出缺少换行符
- **表现**：PTA 提交可能被判格式错误
- **原因**：`printf` 末尾没有 `\n`
- **正确做法**：`printf("f(%.1f) = %.1f\n", x, a);`

## 延伸知识点（询问中涉及）

### `else` 的位置与分号规则
- `else` 放在 `if` 的 `{}` 后面，与 `if` 并列
- `else` 本身不加分号，只有其内部的执行语句才加分号
- `else` 可以单独一行，也可以跟在前一个 `}` 后面

### `scanf` 输入时能否指定小数位
- **不能**。`scanf` 不支持精度控制（如 `%.1f`）
- `scanf` 只负责读取数据，不管截取或格式化
- 只有 `printf` 输出时才能用 `%.nf` 控制小数位

### 计算时如何截取小数位
- C 语言计算时不会自动截取，用完整精度计算
- 如需先截断再计算，需手动处理：`x = (int)(x * 10 + 0.5) / 10.0;`
- 或使用 `math.h` 的 `round` 函数：`x = round(x * 10) / 10.0;`
- 基础题通常只需在 `printf` 输出时控制格式即可

### 更方便的截取函数
- `math.h` 提供 `round()`、`floor()`、`ceil()` 等函数
- 需要 `#include <math.h>`，部分编译器需加 `-lm` 链接参数
- 基础题不建议过早引入，掌握 `printf` 格式控制即可

## 优化与拓展

- 本题逻辑简单，无需复杂优化
- 可以练习用三目运算符简化：`a = (x != 0) ? (1.0 / x) : 0;`
- 注意浮点数比较：本题直接用 `x != 0` 判断即可，但在某些精度敏感场景应考虑误差范围

## 关键知识点总结

| 知识点 | 要点 |
|--------|------|
| `scanf` 读 `double` | 用 `%lf`，不能加精度控制 |
| `printf` 输出 `double` | 用 `%f` 或 `%.nf`，可以控制小数位 |
| 浮点数除法 | 分子分母至少一个是浮点数，否则变成整数除法 |
| `if-else` 结构 | `else` 在 `if` 的 `{}` 后面，本身不加分号 |
| 输出格式 | 注意题目要求的输出格式，末尾加 `\n` |
