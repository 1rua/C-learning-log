# 练习4-10 找出最小值 - 复盘

## 题目要求

输入在一行中首先给出一个正整数 n，之后是 n 个整数，找出其中的最小值，按 `min = 最小值` 格式输出。

## 本题考点

- 数组的定义与使用（`int arr[10000]`）
- `for` 循环遍历数组
- 找最小值/最大值的算法模式
- 最小值初始化的陷阱（初始值不能随便设）
- 边界情况处理（n=1 时只有单个元素）

## 错误记录

### 逻辑错误

#### 错误 1：最小值初始化为 0 导致错误

- **表现**：测试点 2「n=1，最小值为正」答案错误。输入 `1 5`，输出 `min = 0`，实际应为 `min = 5`。
- **原因**：`arr[0] = 0` 把 0 当成了"初始最小值"，但 0 不在输入数据中。当所有输入都是正数时，0 永远比它们小，最终被错误地当作最小值输出。
- **正确做法**：把第一个输入的数作为初始最小值，即用 `scanf("%d", &arr[0])` 代替 `arr[0] = 0`，然后循环只读剩下的 n-1 个数。

**错误代码**：
```c
arr[0] = 0;
for(i = 1; i <= n; i++){
    scanf("%d", &arr[i]);
    if(arr[i] > arr[i-1]) arr[i] = arr[i-1];
}
printf("min = %d", arr[n]);
```

**正确代码**：
```c
scanf("%d", &arr[0]);
for(i = 1; i < n; i++){
    scanf("%d", &arr[i]);
    if(arr[i] > arr[i-1]) arr[i] = arr[i-1];
}
printf("min = %d", arr[n-1]);
```

**为什么测试点 0 和 1 能通过？** 因为测试点 0 包含负数和零，最小值 ≤ 0；测试点 1 最小值为 0。在这两种情况下，初始值 0 恰好不会干扰结果。只有最小值 > 0 时才会暴露问题。

## 优化与拓展

### 不用数组的写法（更优）

本题不需要存储所有数据，可以用一个变量边读边比较：

```c
#include <stdio.h>
int main(void) {
    int n, num, min;
    scanf("%d", &n);
    scanf("%d", &min);          // 第一个数作为初始最小值
    for (int i = 1; i < n; i++) {
        scanf("%d", &num);
        if (num < min) min = num; // 遇到更小的就更新
    }
    printf("min = %d", min);
    return 0;
}
```

### 两种写法对比

| 方式 | 优点 | 缺点 |
|------|------|------|
| 数组存储 | 数据可复用（如后续需要排序等） | O(n) 空间，有数组大小限制 |
| 变量边读边比 | O(1) 空间，无数组大小限制 | 读完就丢，数据无法复用 |

## 关键知识点总结

1. **最小值的初始化要谨慎**：初始值必须是输入数据中的某一个，不能随便设一个"看起来很小的数"（如 0、-1 等）。标准做法是取第一个元素作为初始值。
2. **找最小值/最大值模式**：初始值 = 第一个元素，然后遍历剩余元素，遇到更小/更大的就更新。
3. **测试用例要覆盖全面**：正数、负数、零、n=1 等情况都要考虑，特别是边界情况往往容易出错。
4. **数组能不用就不用**：如果只需要遍历一次得到结果，用变量即可，节省内存且更简洁。
