# 习题2-1 求整数均值 - 复盘

## 题目要求

计算4个整数的和与平均值。

- 输入：一行中给出4个整数，以空格分隔
- 输出：`Sum = 和; Average = 平均值`，平均值精确到小数点后一位

## 本题考点

- 函数的定义、声明和调用
- 函数参数（形参和实参）的理解
- 全局变量与局部变量的作用域区别
- `int` 与 `double` 类型的选择和转换
- `printf` 格式控制符的匹配（`%d` vs `%.1f`）
- 函数定义位置与编译顺序的关系

## 错误记录

### 逻辑错误

#### 错误 1：函数定义放在 `main` 后面导致编译问题
- **表现**：`main` 中调用了 `Sum(a,b,c,d)` 和 `Average(a,b,c,d)`，但函数定义在 `main` 后面
- **原因**：C 编译器从上到下读取代码，调用函数前必须先知道函数的返回类型和参数类型
- **正确做法**：函数定义放在 `main` 前面，或在 `main` 前面加函数声明

```c
// 正确写法 A：定义放前面
double Sum(int a, int b, int c, int d) { ... }
double Average(int a, int b, int c, int d) { ... }
int main(void) { ... }

// 正确写法 B：先声明，后定义
double Sum(int a, int b, int c, int d);
double Average(int a, int b, int c, int d);
int main(void) { ... }
double Sum(int a, int b, int c, int d) { ... }
```

#### 错误 2：`Sum` 返回类型与输出格式不匹配
- **表现**：`Sum` 返回 `double`，但输出时用 `%.1f`，导致 `Sum = 10.0` 而非 `Sum = 10`
- **原因**：题目要求 "Sum = 和" 中的和是整数，应该用 `%d` 输出
- **正确做法**：`Sum` 返回 `int`，`printf` 中对应使用 `%d`

#### 错误 3：全局变量与函数参数同名
- **表现**：定义了全局变量 `a, b, c, d`，函数参数也叫 `a, b, c, d`
- **原因**：函数内部优先使用局部参数，全局变量实际没被用到，造成混淆和冗余
- **正确做法**：去掉全局变量，变量定义在 `main` 内部作为局部变量

### 语法错误

#### 错误 1：函数声明格式错误
- **表现**：`double Sum() , Average();`
- **原因**：这种声明没有参数列表，且用逗号分隔不符合函数声明规范
- **正确做法**：`double Sum(int a, int b, int c, int d);` 或直接用定义放前面的方式

## 优化与拓展

### 更合理的函数设计

```c
#include <stdio.h>

int Sum(int a, int b, int c, int d) {
    return a + b + c + d;
}

double Average(int a, int b, int c, int d) {
    return (a + b + c + d) / 4.0;
}

int main(void) {
    int a, b, c, d;
    scanf("%d %d %d %d", &a, &b, &c, &d);
    printf("Sum = %d; Average = %.1f\n", Sum(a, b, c, d), Average(a, b, c, d));
    return 0;
}
```

### 进一步优化：避免重复计算

当前 `Sum` 和 `Average` 都各自计算了一次 `a + b + c + d`，可以优化：

```c
int main(void) {
    int a, b, c, d;
    scanf("%d %d %d %d", &a, &b, &c, &d);
    int sum = Sum(a, b, c, d);
    printf("Sum = %d; Average = %.1f\n", sum, sum / 4.0);
    return 0;
}
```

或让 `Average` 直接接收 `sum`：

```c
double Average(int sum) {
    return sum / 4.0;
}
```

## 关键知识点总结

1. **函数声明 vs 定义**：声明告诉编译器"有这个函数"（加分号），定义写出具体实现（加花括号）
2. **函数位置**：C 编译器从上往下读，调用函数前必须先知道它的签名（返回类型+参数类型）
3. **全局变量 vs 局部变量**：尽量用局部变量，全局变量会增加代码耦合，容易出错
4. **类型匹配**：`%d` 对应 `int`，`%f`/`%.1f` 对应 `double`，混用会导致输出错误
5. **整数除法 vs 浮点除法**：`Average` 中必须确保至少一个操作数是浮点数，如 `/ 4.0`

## 附加知识点：不定数量输入的处理

### 场景
如果用户输入的数字数量不固定（不是固定的4个），且希望用"空回车"结束输入，该如何实现？

### 核心思路
C 语言的 `scanf("%d")` 无法直接感知"空回车"，因为空白字符会被自动跳过。标准做法是：
> **先用 `fgets` 读一整行，判断是否是空行，再用 `sscanf` 转成数字**

### 关键技术

| 功能 | 函数 | 说明 |
|------|------|------|
| 读一整行 | `fgets(line, size, stdin)` | 包括回车符，需指定最大长度 |
| 去掉换行符 | `line[strcspn(line, "\n")] = '\0'` | 把末尾 `\n` 换成字符串结束符 |
| 判断空行 | `strlen(line) == 0` | 去掉换行后长度为0即空行 |
| 字符串转整数 | `sscanf(line, "%d", &num)` | 类似 `scanf`，但从字符串读取 |
| 验证解析成功 | `sscanf(...) == 1` | 返回成功解析的数据个数 |

### 示例代码

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    int arr[100];
    int n = 0;
    char line[100];
    
    printf("请输入整数（直接回车结束）：\n");
    
    while (fgets(line, sizeof(line), stdin) != NULL) {
        // 去掉末尾换行符
        line[strcspn(line, "\n")] = '\0';
        
        // 空行则结束输入
        if (strlen(line) == 0) {
            break;
        }
        
        // 解析整数，并验证是否成功
        int num;
        if (sscanf(line, "%d", &num) == 1) {
            arr[n] = num;
            n++;
        } else {
            printf("输入无效，请重新输入\n");
        }
    }
    
    // 此时 arr 中有 n 个有效数字
    printf("共输入 %d 个数\n", n);
    
    return 0;
}
```

### 注意事项

#### 1. `scanf` 后接 `fgets` 的问题
如果前面用过 `scanf`，缓冲区会残留回车符，导致 `fgets` 直接读到空行。

**解决**：清空输入缓冲区
```c
int c;
while ((c = getchar()) != '\n' && c != EOF);  // 吃掉残留回车
```

#### 2. 与 Python 对比

| 功能 | Python | C |
|------|--------|---|
| 读一行 | `input()` | `fgets(line, size, stdin)` |
| 判断是否为空 | `if line == ""` | `if (strlen(line) == 0)` |
| 字符串转整数 | `int(line)` | `sscanf(line, "%d", &num)` |
| 去掉末尾换行 | 自动处理 | `line[strcspn(line, "\n")] = '\0'` |

### 结合数组版函数

将不定数量输入与数组参数函数结合：

```c
double Sum(int arr[], int n) {
    double sum = 0;
    for (int i = 0; i < n; i++) {
        sum += arr[i];
    }
    return sum;
}

double Average(int arr[], int n) {
    return Sum(arr, n) / n;
}
```

这样 `main` 用 `fgets` 收集任意数量的输入，再调用 `Sum(arr, n)` 和 `Average(arr, n)` 计算结果。
