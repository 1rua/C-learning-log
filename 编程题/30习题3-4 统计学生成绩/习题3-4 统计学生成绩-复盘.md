# 习题3-4 统计学生成绩 - 复盘

## 题目要求

读入 N 个学生的百分制成绩，统计五分制成绩（A/B/C/D/E）的分布。

- 输入：第一行 N（≤1000），第二行 N 个成绩（空格分隔）
- 输出：A B C D E 的人数，空格分隔，行末无多余空格

## 本题考点

- 数组的定义与使用（固定大小数组 vs 变长数组 VLA）
- `for` 循环遍历数组 + 边读边处理
- 计数器变量初始化（局部变量必须显式赋初值）
- `if-else if-else` 多分支条件判断（利用 else 链简化条件）
- `scanf` 连续读取多个整数（`%d` 自动跳过空白字符）
- 输出格式控制（空格分隔，行末无多余空格）

## 错误记录

### 逻辑错误

#### 错误 1：计数器变量未初始化
- **表现**：程序输出随机数，每次运行结果不同
- **原因**：`int a, b, c, d, e;` 声明了局部变量但不赋初值，C 语言中局部变量初始值是栈上的"垃圾值"。`a++` 会从一个随机数开始加，统计结果完全不可预测
- **正确做法**：`int a = 0, b = 0, c = 0, d = 0, e = 0;`

#### 错误 2：`scores >= 80` 写成了 `scores` 而不是 `scores[i]`
- **表现**：编译通过，但所有成绩都被统计到 B 档
- **原因**：`scores` 是数组名，代表数组首地址（一个指针值），不是某个学生的成绩。`scores >= 80` 是在比较一个地址是否大于等于 80，由于地址通常很大（如 `0x7fff...`），这个条件几乎永远为真
- **正确做法**：所有条件判断都使用 `scores[i]`，即数组下标访问

#### 错误 3：`printf` 放在了循环内部
- **表现**：每读一个成绩就输出一次统计结果，而不是全部统计完后输出一次
- **原因**：`printf` 写在了 `for` 循环的闭合花括号 `}` 之前
- **正确做法**：`printf` 移到 `for` 循环结束后、`return 0` 之前

#### 错误 4：`else if` 条件中存在冗余判断
- **表现**：`else if (scores[i] < 90 && scores[i] >= 80)` 中的 `scores[i] < 90` 是多余的
- **原因**：`else if` 意味着"前面的条件都不成立"，走到 `else if (scores[i] >= 80)` 时，已经隐含了 `scores[i] < 90`。同理后面几个条件也有冗余部分
- **正确做法**：利用 `else` 链的隐含条件，简化判断：
  ```c
  if (scores[i] >= 90) {
      a++;
  } else if (scores[i] >= 80) {
      b++;
  } else if (scores[i] >= 70) {
      c++;
  } else if (scores[i] >= 60) {
      d++;
  } else {
      e++;
  }
  ```
- **注意**：最后一个写成 `else` 而不是 `else if`，因为走到这里成绩必然 `< 60`

### 语法错误

#### 错误 1：`scanf` 格式字符串中写了 `/n`
- **表现**：`scanf("%d/n", &n);` 中 `/n` 不是换行符 `\n`
- **原因**：`/n` 被当作普通字符匹配，`scanf` 期望输入流中紧跟着出现 `/n`，导致读取行为异常
- **正确做法**：`scanf("%d", &n);`，`%d` 本身会自动跳过前面的空白字符

## 优化与拓展

### 优化 1：简化 `else if` 条件

利用 `else` 链的隐含排除逻辑，省略每个条件中的上界判断：

| 修改前 | 修改后 |
|--------|--------|
| `if (s >= 90)` | `if (s >= 90)` |
| `else if (s < 90 && s >= 80)` | `else if (s >= 80)` |
| `else if (s < 80 && s >= 70)` | `else if (s >= 70)` |
| `else if (s < 70 && s >= 60)` | `else if (s >= 60)` |
| `else if (s < 60 && s >= 0)` | `else` |

### 优化 2：不用数组，边读边处理

本题不需要保存所有成绩，可以边读边统计，省去数组：

```c
#include <stdio.h>

int main(void) {
    int n, score, i;
    int a = 0, b = 0, c = 0, d = 0, e = 0;

    scanf("%d", &n);
    for (i = 0; i < n; i++) {
        scanf("%d", &score);
        if (score >= 90) a++;
        else if (score >= 80) b++;
        else if (score >= 70) c++;
        else if (score >= 60) d++;
        else e++;
    }
    printf("%d %d %d %d %d", a, b, c, d, e);
    return 0;
}
```

### 两种写法对比

| 方式 | 优点 | 缺点 |
|------|------|------|
| 数组存储 | 可复用数据（如后续需要求最高分、排序） | 需要额外内存 |
| 边读边处理 | 内存占用小，无需关心 N 上限 | 数据无法复用 |

### 固定数组 vs 变长数组（VLA）vs malloc

| 方式 | 写法 | 适用场景 |
|------|------|----------|
| 固定数组 | `int scores[1000];` | N 有明确上限且不大 |
| 变长数组 | `int scores[n];` | C99+，N 运行时确定 |
| malloc | `int *s = malloc(n * sizeof(int));` | N 很大或函数间传递 |

## 关键知识点总结

1. **局部变量必须初始化**：C 不会自动给局部变量赋 0，忘记初始化会导致随机结果
2. **数组名是地址，不是元素值**：`scores` 和 `scores[i]` 是完全不同的东西
3. **`else if` 链自带"排除"语义**：走到 `else if` 时前面的条件已经不成立，无需重复判断上界
4. **`printf` 位置决定输出时机**：放在循环内 = 每轮输出一次，放在循环外 = 全部完成后输出一次
5. **`scanf` 的 `%d` 自动跳过空白**：格式串中不需要额外加空格或 `\n`
