# 练习2-13 求N分之一序列前N项和 - 复盘

## 题目要求

计算序列 1 + 1/2 + 1/3 + ... + 1/N 的前N项之和，输出格式为 `sum = S`，精确到小数点后6位。

## 本题考点

- `for` 循环遍历 1 到 N
- `double` 双精度浮点数的累加求和
- C 语言整数除法与浮点除法的区别
- `printf` 格式控制 `%.6f`
- 变量初始化（局部变量必须手动初始化）

## 错误记录

### 逻辑错误

#### 错误 1：整数除法导致结果错误
- **表现**：输入 6 时输出 `sum = 1.000000`，而不是正确的 `2.450000`
- **原因**：`s = 1 / n;` 中 `1` 和 `n` 都是 `int` 类型，C 语言整数相除会自动舍去小数部分。因此 `1/2=0`、`1/3=0`...只有 `1/1=1`，最终 sum 只累加了 1
- **正确做法**：写成 `s = 1.0 / n;`，确保至少有一个操作数是浮点数，触发浮点除法

### 语法错误

#### 错误 1：变量未初始化
- **表现**：`double sum, s;` 没有给 `sum` 赋初值
- **原因**：C 语言局部变量不会自动初始化为 0，未初始化的变量可能含有随机垃圾值，导致累加结果不可预期
- **正确做法**：定义时初始化 `double sum = 0, s;`

## 优化与拓展

- 可以省略中间变量 `s`，直接写 `sum += 1.0 / n;`
- 如果 N 很大，累加顺序从大到小（`1.0/N` 到 `1.0/1`）可以减少浮点精度损失
- 对比 Python：`1/2` 在 Python 3 中自动得到 `0.5`，而 C 语言必须显式使用浮点数

## 附加知识点：`printf` 动态指定小数位数

### 问题场景
如果题目要求输入一个整数 `m`，然后输出 `m` 位小数，怎么办？

### 解决方法：`*` 占位符

`printf` 支持用 `*` 动态指定精度（小数位数）：

```c
printf("%.*f", m, sum);
```

- 第一个参数 `m` 表示小数位数
- 第二个参数 `sum` 是要输出的数值

### 示例代码

```c
#include <stdio.h>

int main(void) {
    int n, m;
    double sum = 0;

    scanf("%d %d", &n, &m);

    for (int i = 1; i <= n; i++) {
        sum += 1.0 / i;
    }

    printf("sum = %.*f\n", m, sum);

    return 0;
}
```

### 运行示例

```
输入：6 3
输出：sum = 2.450

输入：6 6
输出：sum = 2.450000
```

### 延伸：动态指定宽度和精度

```c
printf("%*.*f\n", width, precision, sum);
```

| 参数 | 含义 |
|------|------|
| `width` | 总输出宽度（不够补空格） |
| `precision` | 小数位数 |
| `sum` | 要输出的数值 |

### 对比 Python

```python
m = 3
print(f"{sum:.{m}f}")   # Python f-string 动态精度
```

C 语言的 `%.*f` 功能等价，语法不同。

## 关键知识点总结

1. **C 语言整数除法**：两个 `int` 相除，结果仍是 `int`，小数部分直接丢弃
2. **浮点除法触发条件**：至少一个操作数是浮点类型（`float` 或 `double`）
3. **变量初始化**：C 局部变量不会自动清零，累加器必须手动初始化为 0
4. **类型提升**：`1.0 / n` 中，`n` 会被自动提升为 `double` 再参与运算
