# 练习2-11 计算分段函数[2] - 复盘

## 题目要求

计算分段函数 f(x) 的值：

- 当 x >= 0 时，f(x) = x^0.5（即 sqrt(x)）
- 当 x < 0 时，f(x) = (x+1)^2 + 2x + 1/x

输入一个实数 x，按 `f(x) = result` 格式输出，保留两位小数。

## 本题考点

- 分段函数的条件判断（`if-else`）
- `double` 类型变量的使用
- `math.h` 头文件及数学函数的调用
- `scanf`/`printf` 对 `double` 的格式控制（`%lf` / `%f`）
- 输出格式严格匹配题目要求

## 错误记录

无。代码一次通过。

## 优化与拓展

- `pow(x, 0.5)` 和 `sqrt(x)` 效果相同，`sqrt` 语义更直观
- `x < 0` 的分支中，`1/x` 在 x 为 0 时会出现除零错误，但题目输入范围保证了 x < 0 时不会为 0

## 关键知识点总结：math.h 常用函数

| 函数 | 功能 | 示例 |
|------|------|------|
| `sqrt(x)` | 平方根 | `sqrt(16.0)` → `4.0` |
| `pow(x, y)` | x 的 y 次幂 | `pow(2.0, 3.0)` → `8.0` |
| `fabs(x)` | 绝对值（浮点数） | `fabs(-3.5)` → `3.5` |
| `abs(x)` | 绝对值（整数） | `abs(-5)` → `5` |
| `ceil(x)` | 向上取整 | `ceil(2.3)` → `3.0` |
| `floor(x)` | 向下取整 | `floor(2.9)` → `2.0` |
| `round(x)` | 四舍五入 | `round(2.5)` → `3.0` |

> 注意：`sqrt` 和 `pow` 的参数和返回值都是 `double` 类型。
