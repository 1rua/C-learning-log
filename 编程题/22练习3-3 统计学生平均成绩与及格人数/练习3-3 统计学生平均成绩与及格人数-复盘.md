# 练习3-3 统计学生平均成绩与及格人数 - 复盘

## 题目要求

计算学生们的平均成绩，并统计及格（成绩不低于60分）的人数。

- 输入：第一行给出非负整数N（学生人数），第二行给出N个非负整数（学生成绩，空格分隔）
- 输出：`average = 成绩均值`（精确到小数点后一位），`count = 及格人数`

## 本题考点

- 数组的定义与使用（`int N[100000]`）
- `for` 循环遍历数组
- `scanf` 连续读取多个数据
- 累加求和与平均值计算
- 条件判断统计及格人数
- 边界情况处理（`n = 0` 时除零保护）
- 输出格式控制（`%.1f` 保留一位小数）

## 错误记录

### 逻辑错误

#### 错误 1：数组大小不足导致段错误
- **表现**：测试点1"人数较多，但没有人及格"出现段错误
- **原因**：数组定义为 `int N[100]`，当输入人数超过100时，访问 `N[100]` 及之后的位置发生数组越界，导致段错误
- **正确做法**：根据题目可能的输入规模，将数组开足够大，如 `int N[100000]`

#### 错误 2：`n = 0` 时未处理除零情况
- **表现**：测试点2"没有学生"答案错误
- **原因**：当 `n = 0` 时，`avg / n` 会导致除零错误或未定义行为
- **正确做法**：在计算平均值前判断 `n` 是否为0，若 `n == 0` 则直接输出 `average = 0.0`

#### 错误 3：`n = 0` 时输出格式不符合要求
- **表现**：输出 `average = 0` 而不是 `average = 0.0`
- **原因**：题目要求平均值精确到小数点后一位，即使为0也要输出 `0.0`
- **正确做法**：`printf("average = 0.0");`

### 语法错误

#### 错误 1：`scanf` 格式字符串中多余 `\n`
- **表现**：`scanf("%d\n", &n);` 导致读取行为异常
- **原因**：`scanf` 格式中的 `\n` 会尝试读取并丢弃空白字符，直到遇到非空白字符，可能导致程序等待额外输入或读取异常
- **正确做法**：`scanf("%d", &n);`，`%d` 本身会自动跳过前面的空白

#### 错误 2：`scanf` 格式字符串中多余空格
- **表现**：`scanf("%d ", &N[i]);` 导致最后一次读取后等待额外输入
- **原因**：`%d` 后的空格表示"读取整数后，再读取并丢弃任意数量空白直到遇到非空白字符"
- **正确做法**：`scanf("%d", &N[i]);`

#### 错误 3：循环边界错误
- **表现**：`for(i = 0; i <= n; i++)` 导致数组越界和多读数据
- **原因**：数组下标从0开始，n个元素的下标范围是 `0` 到 `n-1`
- **正确做法**：`for(i = 0; i < n; i++)`

## 优化与拓展

### 不用数组的写法

本题其实可以边读边处理，不需要存储所有成绩：

```c
#include <stdio.h>

int main(void) {
    int n, score, count = 0;
    double sum = 0;
    
    scanf("%d", &n);
    
    for (int i = 0; i < n; i++) {
        scanf("%d", &score);
        sum += score;
        if (score >= 60) count++;
    }
    
    if (n == 0) {
        printf("average = 0.0\ncount = 0");
    } else {
        printf("average = %.1f\ncount = %d", sum / n, count);
    }
    
    return 0;
}
```

### 两种写法对比

| 方式 | 优点 | 缺点 |
|-----|------|------|
| 数组存储 | 可复用数据（如求最高分、排序等） | 需要额外内存，有数组大小限制 |
| 边读边处理 | 内存占用小，无数组大小限制 | 数据无法复用 |

## 关键知识点总结

1. **数组大小要足够**：根据题目数据范围开数组，避免因数据量大导致越界
2. **数组越界很危险**：C语言不会检查数组越界，越界访问会导致段错误或不可预期行为
3. **除零保护**：做除法前必须判断除数是否为0
4. **`scanf` 格式要简洁**：不要在 `%d` 后加空格或 `\n`
5. **循环边界**：n个元素用 `i < n`，不要用 `i <= n`
6. **输出格式严格匹配**：题目要求几位小数就输出几位，即使值为0
