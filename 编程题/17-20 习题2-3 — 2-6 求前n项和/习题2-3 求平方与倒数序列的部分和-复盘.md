# 习题2-3 求平方与倒数序列的部分和 - 复盘

## 题目要求

对两个正整数 m 和 n（m≤n）编写程序，计算序列和：

m² + 1/m + (m+1)² + 1/(m+1) + ... + n² + 1/n

输入：一行中给出两个正整数 m 和 n，空格分隔
输出：sum = S，精确到小数点后六位

## 本题考点

- `for` 循环遍历指定范围 [m, n]
- `double` 类型累加求和
- 浮点数除法（`1.0 / i` 避免整数除法）
- `pow()` 函数计算平方
- 变量初始化（局部变量必须手动赋初值）
- 循环变量与边界变量的分离使用

## 错误记录

### 逻辑错误

#### 错误 1：循环变量未初始化导致累加结果错误
- **表现**：`double sum;` 未初始化，累加结果含有随机垃圾值
- **原因**：C 语言局部变量不会自动初始化为 0，未初始化的 `double` 变量可能是一个很小的随机数或垃圾值，导致最终求和结果错误
- **正确做法**：定义时立即初始化 `double sum = 0.0;`

## 优化与拓展

### 循环变量与边界变量分离

**建议**：当循环范围由输入变量（如 m, n）决定时，循环内部最好使用独立的中间变量（如 `i`）作为遍历变量，避免直接修改或混淆原始的边界变量。

**好处**：
- 保持原始输入值不变，便于后续调试或复用
- 代码语义更清晰：`m` 和 `n` 始终表示输入的边界，`i` 表示当前遍历位置
- 避免意外修改边界导致逻辑错误

**示例对比**：

不推荐（虽然本题不影响，但习惯不好）：
```c
for(; m <= n; m++) {  // m 被修改了
    sum += pow(m, 2) + 1.0 / m;
}
```

推荐：
```c
for(int i = m; i <= n; i++) {  // i 是独立的循环变量
    sum += pow(i, 2) + 1.0 / i;
}
// m 和 n 保持原值不变
```

### 本题的其他实现方式

**不用 pow 函数，直接用乘法**：
```c
sum += i * i + 1.0 / i;
```
- `i * i` 比 `pow(i, 2)` 更高效，因为 pow 是通用函数，涉及浮点运算和函数调用开销
- 对于整数平方，直接乘法更直观且性能更好

## 关键知识点总结

1. **局部变量必须初始化**：C 语言不会自动给局部变量赋初值，未初始化的变量含有随机值
2. **整数除法陷阱**：`1 / i` 当 i 为 int 时结果为 0，必须写成 `1.0 / i` 确保浮点除法
3. **循环变量独立**：使用独立的循环变量 `i`，不修改原始的 m, n
4. **循环边界包含**：`i <= n` 确保 n 本身也被计算进去
