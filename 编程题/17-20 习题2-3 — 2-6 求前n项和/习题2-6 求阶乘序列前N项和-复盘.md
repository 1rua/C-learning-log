# 习题2-6 求阶乘序列前N项和 - 复盘

## 题目要求

计算序列 1! + 2! + 3! + ... 的前N项之和，N 不超过 12，输出整数结果。

## 本题考点

- 函数的定义与调用
- 函数参数类型声明
- 局部变量初始化
- 循环结构
- 阶乘的计算方法

## 错误记录

### 语法错误

#### 错误 1：函数参数未声明类型
- **表现**：`double factorial(n)` 编译报错
- **原因**：C 语言函数参数必须明确写出类型，不能像 Python 那样省略
- **正确做法**：`int factorial(int n)`

### 逻辑错误

#### 错误 1：花括号位置错误导致循环范围混乱
- **表现**：`printf` 和 `return 0` 被包在 `for` 循环内部
- **原因**：对 `{}` 的作用范围理解不清，导致程序只循环一次就结束
- **正确做法**：把输出和返回语句移到循环外面

#### 错误 2：局部变量未初始化
- **表现**：`sum` 和 `result` 含有随机值，结果错误
- **原因**：C 语言局部变量不会自动初始化为 0，与 Python 不同
- **正确做法**：定义时赋初值 `sum = 0`、`result = 1`

#### 错误 3：函数返回值类型不匹配
- **表现**：`factorial` 声明返回 `double`，但 `sum` 是 `int`
- **原因**：类型不一致导致隐式转换
- **正确做法**：统一使用 `int` 或 `long long`

## 关键知识点总结

1. **C 函数必须明确参数类型**：`int func(int a)`，不能省略
2. **局部变量必须手动初始化**：C 不会自动清零
3. **花括号决定作用范围**：注意 `{}` 配对，避免把后续代码包进循环
4. **阶乘从 1 开始乘**：`result = 1`，不是 0
