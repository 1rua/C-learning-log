# 练习3-4 统计字符 - 复盘

## 题目要求

输入10个字符，统计其中英文字母、空格或回车、数字字符和其他字符的个数。

- 输入：10个字符（最后一个回车表示输入结束，不算在内）
- 输出：`letter = X, blank = Y, digit = Z, other = W`

## 本题考点

- `for` 循环固定次数遍历
- `getchar()` 逐个读取字符
- 字符分类判断（字母、空格/回车、数字、其他）
- 字符比较使用单引号（如 `'a'`、`' '`、`'\n'`）
- 逻辑运算符 `&&` 和 `||` 的使用
- 比较运算符 `==` 与赋值运算符 `=` 的区别
- 单引号 `' '` vs 双引号 `" "` 的区别

## 错误记录

### 逻辑错误

#### 错误 1：多余的 `scanf` 导致多读一个字符
- **表现**：测试点0、2、3、4答案错误，只有测试点1（10个回车）碰巧正确
- **原因**：代码中同时使用了 `scanf("%c", &ch)` 和 `getchar()`，`scanf` 先读走第一个字符，循环里的 `getchar()` 又读了10个，总共读了11个字符，但只统计了后10个
- **正确做法**：删掉 `scanf`，直接用 `for` 循环10次 `getchar()` 读取

### 语法错误

#### 错误 1：字符比较用了双引号
- **表现**：编译报错，类型不匹配
- **原因**：`"a"` 是字符串（返回地址），`'a'` 才是字符。用双引号比较字符会导致类型错误和逻辑错误
- **正确做法**：所有字符比较都用单引号，如 `ch >= 'a'`、`ch == ' '`、`ch == '\n'`

#### 错误 2：`else if` 条件中用了赋值号 `=`
- **表现**：`ch = '\n'` 把回车赋给 `ch`，条件判断逻辑错误
- **原因**：`=` 是赋值，`==` 才是比较相等
- **正确做法**：`ch == ' ' || ch == '\n'`

#### 错误 3：循环次数错误
- **表现**：`i <= 10` 导致循环11次
- **原因**：从0开始时，`<= 10` 会执行11次（0到10）
- **正确做法**：`i < 10`，只循环10次

#### 错误 4：用了 `getwchar()` 而不是 `getchar()`
- **原因**：`getwchar()` 是宽字符版本，用于读取中文等多字节字符，本题ASCII字符用 `getchar()` 即可
- **正确做法**：`ch = getchar()`

#### 错误 5：`printf` 输出缺少换行符
- **原因**：PTA部分题目对输出格式要求严格，末尾最好加 `\n`
- **正确做法**：`printf("letter = %d, blank = %d, digit = %d, other = %d\n", ...)`

## 优化与拓展

### 使用 `isalpha`、`isdigit`、`isspace` 函数（需要 `<ctype.h>`）

```c
#include <stdio.h>
#include <ctype.h>

int main(void) {
    int ch, i;
    int letter = 0, blank = 0, digit = 0, other = 0;

    for (i = 0; i < 10; i++) {
        ch = getchar();
        
        if (isalpha(ch)) {
            letter++;
        } else if (ch == ' ' || ch == '\n') {
            blank++;
        } else if (isdigit(ch)) {
            digit++;
        } else {
            other++;
        }
    }
    
    printf("letter = %d, blank = %d, digit = %d, other = %d\n",
           letter, blank, digit, other);
    
    return 0;
}
```

**注意**：`isspace(ch)` 会把空格、回车、制表符等都算作空白，但本题只要求空格或回车，所以 `blank` 的判断还是手动写更精确。

## 关键知识点总结

1. **`getchar()` 不需要配合 `scanf`**：`getchar()` 是独立函数，直接从输入缓冲区读字符
2. **单引号是字符，双引号是字符串**：`'a'` 是 `char` 类型，`"a"` 是 `char*` 类型
3. **`==` 是比较，`=` 是赋值**：条件判断必须用 `==`
4. **`&&` 是逻辑与，`||` 是逻辑或**：`&&` 优先级高于 `||`，复杂条件建议加括号
5. **循环边界**：固定次数用 `for(i = 0; i < n; i++)`，不要写成 `i <= n`
6. **`getchar()` 返回 `int`**：虽然返回的是字符的ASCII码值，但类型是 `int`，用 `int ch` 接收更安全
