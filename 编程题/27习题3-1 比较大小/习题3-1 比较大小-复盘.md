# 习题3-1 比较大小 - 复盘

## 题目要求

输入3个整数，从小到大排序后输出，数字之间用 `->` 分隔。

输入样例：`4 2 8`
输出样例：`2->4->8`

## 本题考点

- 数组的定义与使用（`int arr[3]`）
- `for` 循环的嵌套（外层控制趟数，内层控制比较）
- 冒泡排序算法（Bubble Sort）
- 变量交换的三步操作（临时变量法）
- 数组越界的风险与防范
- 输出格式控制（最后一个元素后不加分隔符）

## 错误记录

### 逻辑错误

#### 错误 1：只做了一趟冒泡，排序不完整
- **表现**：输入 `4 8 2`，输出 `4 2 8`，而不是 `2 4 8`
- **原因**：冒泡排序每趟只能把当前最大的数"沉"到最后。一趟比较只能让相邻元素交换一次，远处的元素（如 `arr[0]` 和 `arr[2]`）需要多趟才能传递到位。只有外层循环时，内层的单趟扫描无法完成全排序
- **正确做法**：外层加一个循环控制趟数，3 个数需要 2 趟（n-1 趟）

#### 错误 2：读入、排序、打印三个步骤互相嵌套
- **表现**：`scanf` 写在了排序循环内部，`printf` 写在了比较循环内部，导致代码逻辑混乱
- **原因**：三个步骤应该是**顺序执行**的独立代码块，而不是嵌套关系
- **正确做法**：
  ```
  步骤1：读入（一个 for 循环）
  步骤2：排序（两层 for 循环）
  步骤3：输出（一个 for 循环）
  ```
  三个步骤平级，不要互相嵌套

#### 错误 3：变量交换顺序写反
- **表现**：
  ```c
  arr[i] = z;        // z 未初始化，arr[i] 被赋了随机值
  arr[i+1] = arr[i]; // arr[i] 已经是随机值了
  z = arr[i];        // 交换失败，原值丢失
  ```
- **原因**：交换两个变量的正确顺序是「先保存 → 再覆盖 → 最后恢复」，即：`临时变量 = A; A = B; B = 临时变量;`
- **正确做法**：
  ```c
  z = arr[i];          // 1. 先保存 arr[i] 的值
  arr[i] = arr[i+1];   // 2. 把 arr[i+1] 赋给 arr[i]
  arr[i+1] = z;        // 3. 把保存的值赋给 arr[i+1]
  ```

### 语法错误

#### 错误 1：变量未初始化就使用
- **表现**：`scanf("%d", &arr[i]);` 中 `i` 未赋值，访问了随机内存位置
- **原因**：C 语言中局部变量不会自动初始化，`i` 里是随机垃圾值
- **正确做法**：在 `for` 循环中初始化 `i`：`for(i = 0; i < 3; i++)`

#### 错误 2：数组越界访问
- **表现**：当 `i = 2` 时，`arr[i+1]` 即 `arr[3]`，但数组只有 3 个元素（索引 0~2）
- **原因**：C 语言不检查数组越界，访问 `arr[3]` 会读到未知内存，属于未定义行为
- **正确做法**：内层循环条件应为 `i < n-1`（即 `i < 2`），确保 `i+1` 不超过 `n-1`

#### 错误 3：未使用的变量
- **表现**：定义了 `a, b, c` 三个变量但从未使用
- **原因**：从「独立变量方案」切换到「数组方案」后，忘记删除旧变量
- **正确做法**：删除未使用的变量，保持代码整洁

## 优化与拓展

### 通用版本：支持 n 个数的排序

当前代码写死了 3 个数，只需将所有硬编码的数字替换为变量 `n`：

| 当前（3个数） | 通用（n个数） |
|---|---|
| `int arr[3]` | `int arr[MAXN]` |
| `scanf` 写死 3 个 `%d` | `for` 循环 `scanf` n 次 |
| `p < 2` | `p < n-1` |
| `i < 2` | `i < n-1-p`（优化版） |
| `o < 3` | `o < n` |
| `o < 2` | `o < n-1` |

其中 `n-1-p` 是冒泡排序的优化：每趟结束后，最大的 p 个数已沉到最后，无需再比较。

### 不用数组的方案（仅适用于 3 个数）

对于只有 3 个数的情况，也可以直接用 `if` 两两比较 + 交换：

```c
if (a > b) { t = a; a = b; b = t; }
if (a > c) { t = a; a = c; c = t; }
if (b > c) { t = b; b = c; c = t; }
```

这种方式不需要数组和嵌套循环，但无法扩展到 n 个数。

### 和 Python 的对比

| | Python | C |
|---|---|---|
| 排序 | `arr.sort()` 一行 | 需要手写冒泡排序 |
| 交换 | `a, b = b, a` | `t = a; a = b; b = t;` |
| 数组 | `list`，自动扩容 | `int arr[N]`，固定大小 |
| 输出分隔 | `"->".join(map(str, arr))` | 手动循环 + `if` 判断最后一项 |

## 关键知识点总结

1. **冒泡排序原理**：外层控制趟数（n-1 趟），内层相邻比较，每趟把当前最大值沉到最后
2. **变量交换三步走**：`临时 = A; A = B; B = 临时;`，顺序不能错
3. **数组越界不报错但很危险**：C 语言不检查越界，访问越界位置是未定义行为
4. **三个步骤要分开**：读入、处理（排序）、输出，应该是三个独立的代码块
5. **循环嵌套理解**：外层每执行一次，内层执行一整轮；冒泡排序就是外层控制轮数、内层做比较
6. **局部变量不初始化有随机值**：定义变量后必须赋初值，否则里面是垃圾值
