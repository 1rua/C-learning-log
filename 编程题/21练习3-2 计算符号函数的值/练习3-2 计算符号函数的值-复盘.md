# 练习3-2 计算符号函数的值 - 复盘

## 题目要求

对于任一整数 n，符号函数 sign(n) 的定义如下：

- 当 n < 0 时，sign(n) = -1
- 当 n = 0 时，sign(n) = 0
- 当 n > 0 时，sign(n) = 1

输入一个整数 n，按照格式 `sign(n) = 函数值` 输出该整数 n 对应的函数值。

## 本题考点

- `if-else if-else` 多分支条件判断
- 关系运算符 `==` 与赋值运算符 `=` 的区别
- `else` 的语法规则（不能带条件）
- `scanf` 读取整数输入
- `printf` 格式化输出

## 错误记录

### 语法错误

#### 错误 1：`else if` 中使用了赋值号 `=` 而非比较号 `==`
- **表现**：`else if(n = 0)`
- **原因**：在 C 语言中，`=` 是赋值操作，`==` 才是判断是否相等。`n = 0` 会把 `0` 赋给 `n`，然后整个表达式的值就是 `0`（假），所以这个分支永远不会执行，而且 `n` 的值还被改成了 `0`
- **正确做法**：`else if (n == 0)`

#### 错误 2：`else` 后面带了条件
- **表现**：`else(n > 0)`
- **原因**：`else` 表示"否则"，已经隐含了"前面所有条件都不满足"的意思，后面不能再跟条件。如果想带条件，应该用 `else if`；如果确定只剩最后一种情况，直接用 `else` 即可
- **正确做法**：`else {` 或 `else if (n > 0) {`

## 优化与拓展

### 更简洁的实现方式

本题逻辑简单，也可以直接用 `if-else if-else` 的裸 `else` 结尾：

```c
if (n < 0) {
    sign = -1;
} else if (n == 0) {
    sign = 0;
} else {
    sign = 1;
}
```

### 使用三目运算符（了解即可）

```c
sign = (n > 0) ? 1 : ((n < 0) ? -1 : 0);
```

- 三目运算符 `? :` 可以简化简单的条件赋值，但嵌套过多会降低可读性
- 初学者建议先掌握 `if-else` 写法

## 关键知识点总结

1. **`=` vs `==`**：`=` 是赋值，`==` 是比较相等。这是 C 语言新手最高频的错误之一
2. **`else` 的语法**：`else` 后面不能写条件，要么用裸 `else`，要么用 `else if`
3. **条件覆盖完整性**：本题三个分支覆盖了所有整数情况，逻辑上是完整的
4. **变量初始化**：虽然本题 `sign` 在三个分支都被赋值，但养成定义时初始化的习惯更好：`int sign = 0;`
