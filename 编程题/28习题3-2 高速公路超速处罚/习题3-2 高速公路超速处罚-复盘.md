# 习题3-2 高速公路超速处罚 - 复盘

## 题目要求

输入车速和限速，判断处理意见：
- 正常行驶 → 输出 `OK`
- 超速 ≥ 10% → 输出 `Exceed x%. Ticket 200`
- 超速 ≥ 50% → 输出 `Exceed x%. License Revoked`

其中 x 是超速百分比，精确到整数（四舍五入）。

## 本题考点

- `if-else if-else` 多分支条件判断（先判断 50% 再判断 10%，顺序不能反）
- 浮点数比较的精度陷阱（`0.1` 在二进制中是无限循环小数）
- 整数除法与四舍五入（需要 `+0.5` 再取整）
- `printf` 格式控制（`%%` 输出百分号 `%`）
- 用整数运算替代浮点运算避免精度问题（`(a-b)*100 >= b*50` 代替 `a >= b*1.5`）

## 错误记录

### 逻辑错误

#### 错误 1：浮点数比较导致边界判断错误
- **表现**：测试点 3 "超过百分之10" 答案错误，部分边界值被误判为 "OK"
- **原因**：`a >= b + b * 0.1` 中 `0.1` 在二进制中无法精确表示（类似十进制 `1/3 = 0.333...`），`b * 0.1` 的结果可能比实际值略大。例如 b=10 时，`b*0.1 ≈ 1.0000000000000000555...`，`b + b*0.1 ≈ 11.000000000000000555...`，a=11 时 `11 >= 11.000...` 为 false，导致本应输出 "Ticket 200" 的结果变成了 "OK"
- **正确做法**：全部用整数运算，避免浮点数：
  ```c
  // 超速 >= 50%：等价于 (a-b)/b >= 0.5，即 (a-b)*100 >= b*50
  if ((a - b) * 100 >= b * 50)
  // 超速 >= 10%：等价于 (a-b)/b >= 0.1，即 (a-b)*100 >= b*10
  else if ((a - b) * 100 >= b * 10)
  ```

#### 错误 2：整数除法截断导致百分比少 1
- **表现**：样例 `200 120`，代码输出 `66%`，期望 `67%`
- **原因**：`(a-b)*100/b` 是整数除法，直接截断小数部分。`(200-120)*100/120 = 8000/120 = 66.66...` 截断为 66
- **正确做法**：加 0.5 再取整实现四舍五入：
  ```c
  (int)((a - b) * 100.0 / b + 0.5)
  ```

### 语法错误

#### 错误 1：`else if` 写成了 `if else`
- **表现**：编译错误
- **原因**：C 语言中正确的多分支关键字是 `else if`，不能写成 `if else`
- **正确做法**：`else if (条件)`

#### 错误 2：`printf` 中 `%` 未转义
- **表现**：`printf("Exceed %d%. License Revoked", ...)` 输出异常
- **原因**：`%` 在 `printf` 格式字符串中是特殊字符，要输出字面量 `%` 必须写成 `%%`
- **正确做法**：`printf("Exceed %d%%. License Revoked", ...)`

## 优化与拓展

### 最终正确代码

```c
#include <stdio.h>

int main(void) {
    int a, b;
    scanf("%d %d", &a, &b);
    if ((a - b) * 100 >= b * 50) {
        printf("Exceed %d%%. License Revoked", (int)((a - b) * 100.0 / b + 0.5));
    }
    else if ((a - b) * 100 >= b * 10) {
        printf("Exceed %d%%. Ticket 200", (int)((a - b) * 100.0 / b + 0.5));
    }
    else {
        printf("OK");
    }
    return 0;
}
```

### 用纯整数实现四舍五入（避免浮点数）

```c
// 公式：(x * 10 + 5) / 10 实现四舍五入到整数
// 但这里需要先乘 100 再除 b，所以：
int percent = ((a - b) * 1000 / b + 5) / 10;
```

## 关键知识点总结

1. **浮点数比较不可靠**：`0.1`、`0.2` 等小数在二进制中无法精确表示，涉及等值判断时尽量用整数运算
2. **整数除法的四舍五入**：`(int)(x + 0.5)` 或 `(x * 10 + 5) / 10` 实现
3. **`printf` 输出 `%`**：必须写成 `%%`，否则被当作格式说明符
4. **多分支顺序**：范围大的条件（≥50%）先判断，范围小的（≥10%）后判断
5. **`else if` 不是 `if else`**：C 语言关键字顺序固定
