# 练习2-9 整数四则运算 - 复盘

## 题目要求

读取两个正整数 A 和 B，在 4 行中按照格式 "A 运算符 B = 结果" 顺序输出和、差、积、商。

输入样例：`3 2`

输出样例：
```
3 + 2 = 5
3 - 2 = 1
3 * 2 = 6
3 / 2 = 1
```

---

## 本题考点

- `scanf` 读取多个变量
- `printf` 格式化输出
- 整数四则运算
- 整数除法的截断特性
- C89/C99 变量声明位置差异

---

## 代码分析

### 你的实现

```c
#include <stdio.h>
int main(void){
    int A , B;
    scanf("%d\n%d" , &A , &B);
    int he,cha,ji,shang; 
    he = A + B;
    cha = A - B;
    ji = A * B;
    shang = A / B;
    printf("%d + %d = %d\n" , A , B , he);
    printf("%d - %d = %d\n" , A , B , cha);
    printf("%d * %d = %d\n" , A , B , ji);
    printf("%d / %d = %d\n" , A , B , shang);
    return 0;
}
```

---

## 优化与拓展

### 1. scanf 格式字符串的潜在问题

你的代码：`scanf("%d\n%d", &A, &B);`

- 题目输入是 `3 2`（同一行，空格分隔）
- `\n` 在 `scanf` 格式字符串中表示**读取并匹配一个换行符**
- 如果输入真的是空格分隔的同一行数据，`\n` 会导致 `scanf` 等待用户输入换行，可能产生意外行为
- **更安全的写法**：`scanf("%d %d", &A, &B);`

### 2. 变量声明位置

你的代码把变量声明放在了 `scanf` 之后：

```c
scanf("%d\n%d", &A, &B);
int he, cha, ji, shang;  // C99 支持，C89 不支持
```

- **C89 标准**：所有变量必须在代码块开头声明
- **C99 及以后**：支持随处声明
- 如果编译器严格按 C89 编译，这段代码会报错
- **建议**：为了兼容性，变量声明尽量放在函数开头

### 3. 先计算再输出 vs 直接嵌入运算

你的做法（先计算）：
```c
int he = A + B;
printf("%d + %d = %d\n", A, B, he);
```

更简洁的做法（直接嵌入）：
```c
printf("%d + %d = %d\n", A, B, A + B);
```

- 如果结果只用一次，直接嵌入更简洁
- 如果结果要复用，先定义变量更好

### 4. 变量命名建议

```c
int he, cha, ji, shang;  // 拼音命名
```

建议用英文命名，提高可读性：
```c
int sum, diff, product, quotient;
```

## 关键知识点总结

### 整数除法

```c
3 / 2  // 结果是 1，不是 1.5
```

- C 语言中两个整数相除，结果**截断小数部分**
- 这是本题的核心考点之一
- 如果需要浮点结果，至少有一个操作数要是浮点类型：
  ```c
  3.0 / 2    // 1.5
  3 / 2.0    // 1.5
  (double)3 / 2  // 1.5
  ```

### scanf 读取多个变量

```c
scanf("%d %d", &a, &b);  // 空格、换行、制表符都能分隔
```

- `%d %d` 之间的空格表示**跳过任意空白字符**
- 不需要用 `\n` 来匹配换行
- 每个变量前都要加 `&`（取地址）

### printf 参数求值

```c
printf("%d + %d = %d\n", a, b, a + b);
```

- `printf` 是**变参函数**，参数按位置对应格式符
- 表达式 `a + b` 会在调用时求值，结果作为参数传入
- C 语言不支持 Python 的 f-string 那种字符串内嵌表达式
