# 练习2-12 输出华氏-摄氏温度转换表 - 复盘

## 题目要求

输入2个正整数lower和upper（lower≤upper≤100），输出一张取值范围为[lower，upper]、且每次增加2华氏度的华氏-摄氏温度转换表。

温度转换公式：C = 5 × (F - 32) / 9

- 若输入范围合法，第一行输出 "fahr celsius"，接着每行输出一个华氏温度（整型）与对应的摄氏温度（占据6个字符宽度，靠右对齐，保留1位小数）
- 若输入不合法（lower > upper），输出 "Invalid."

## 本题考点

- `for` 循环的正确使用（循环变量、条件、增量）
- C语言中**不支持**连续比较（`a <= b <= c` 是错误的）
- `scanf` 格式控制符的正确书写
- `printf` 格式控制符的精确控制（`%6.1f` 表示6字符宽度、靠右对齐、1位小数）
- 整数除法与浮点数除法的区别（`5 / 9` vs `5.0 / 9.0`）
- 输入合法性判断

## 错误记录

### 逻辑错误

#### 错误1：试图用 `if` 代替循环
- **表现**：只输出了一次结果，而不是一张表
- **原因**：题目要求输出多个温度值，需要用循环结构（`for` 或 `while`），而不是单次 `if` 判断
- **正确做法**：使用 `for` 循环，从 `lower` 开始，每次增加2，直到超过 `upper`

#### 错误2：`for` 循环条件写错，导致死循环/重复输出
- **表现**：评测显示"答案错误"，循环没有正确遍历温度值
- **原因**：`for(fahr = lower; lower <= upper; lower = lower + 2)` 中，循环增量改变的是 `lower`，但输出用的是 `fahr`，导致 `fahr` 永远不变，重复输出同一个值
- **正确做法**：循环增量应该改变 `fahr`：`for (fahr = lower; fahr <= upper; fahr += 2)`

#### 错误3：`for` 循环初始化只执行一次，赋值后变量独立
- **表现**：误以为 `fahr = lower` 会让 `fahr` 一直跟随 `lower` 变化
- **原因**：`for` 循环的初始化部分**只执行一次**，之后 `fahr` 和 `lower` 是两个独立变量。`lower` 自增不会影响 `fahr`
- **正确做法**：循环增量必须和循环变量一致，让 `fahr` 自己推进：`fahr += 2`

### 语法错误

#### 错误1：`scanf` 格式控制符写错
- **表现**：`scanf("%d 23d", &lower, &upper);`
- **原因**：第二个 `%d` 写成了 `23d`，导致 `upper` 无法正确读取
- **正确做法**：`scanf("%d %d", &lower, &upper);`

#### 错误2：连续比较
- **表现**：`if (lower <= upper <= 100)`
- **原因**：C语言不支持连续比较，该表达式会被解析为 `(lower <= upper) <= 100`，结果永远是真（0或1都≤100）
- **正确做法**：`if (lower <= upper && upper <= 100)`，用逻辑与 `&&` 连接两个条件

#### 错误3：`printf` 格式不对
- **表现**：`printf("%d      %.1f\n", fahr, celsius);`
- **原因**：题目要求摄氏温度占据6个字符宽度、靠右对齐。手动敲空格无法保证精确宽度
- **正确做法**：`printf("%d %6.1f\n", fahr, celsius);`，用 `%6.1f` 自动处理宽度和对齐

#### 错误4：`Invalid` 大小写和标点不对
- **表现**：`printf("invalid");`
- **原因**：题目要求输出 `"Invalid."`（首字母大写，末尾有句号）
- **正确做法**：`printf("Invalid.\n");`

#### 错误5：整数除法导致精度丢失
- **表现**：`celsius = (fahr - 32) * 5 / 9;`
- **原因**：C语言中整数除以整数结果还是整数，会截断小数部分
- **正确做法**：`celsius = 5.0 * (fahr - 32) / 9.0;`，用浮点数参与计算

## 优化与拓展

- 本题已经是最直接的循环遍历，没有更优的算法
- 可以尝试用 `while` 循环重写，加深对循环的理解
- 注意 `fahr += 2` 和 `fahr = fahr + 2` 是等价的，前者更简洁

## 关键知识点总结

1. **C语言循环三要素**：初始化、条件、增量，三者要围绕同一个变量
2. **C语言不支持连续比较**：`a <= b <= c` 是错误的，必须用 `a <= b && b <= c`
3. **整数除法陷阱**：`5 / 9` 在C语言中等于 `0`，因为都是整数。要让编译器按浮点数算，至少有一个操作数是浮点数
4. **`printf` 宽度控制**：`%6.1f` 中，`6` 是总宽度，`.1` 是小数位数，默认靠右对齐
5. **严格匹配输出格式**：OJ题目对输出格式要求极其严格，空格、换行、大小写、标点都要和题目一致
