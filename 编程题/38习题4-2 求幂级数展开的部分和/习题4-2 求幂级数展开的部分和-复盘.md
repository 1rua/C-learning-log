# 习题4-2 求幂级数展开的部分和 - 复盘

## 题目要求

已知函数 eˣ 可以展开为幂级数 `1 + x + x²/2! + x³/3! + ... + xᵏ/k! + ...`。给定实数 x∈[0,5]，求幂级数部分和，**一直继续到最后一项的绝对值小于 0.00001**，保留小数点后四位。

## 本题考点

- **幂级数展开（泰勒级数）**：eˣ 的泰勒展开公式，每一项为 `xᵏ/k!`
- **循环终止条件的设计**：`for` 条件前置 vs `do-while` 条件后置 vs `for + break` 中途判断，三种写法对"最后一项"的影响
- **阶乘的递推计算**：`arr[i] = arr[i-1] * i`，避免每轮重新计算阶乘
- **整数溢出意识**：`int` 只能存到 12!（约 4.79 亿），13! 已超 21 亿，必须用 `double` 存阶乘
- **递推公式的优越性**：`term = term * x / k` 比分别计算 `pow(x,k)` 和 `k!` 更精确、更高效
- **浮点数精度与四舍五入边界**：`x=5` 时差一项就导致第 4 位小数差 1，刚好卡在四舍五入边界上

## 错误记录

### 逻辑错误

#### 错误 1：阶乘数组用 `int` 导致溢出
- **表现**：`x=5` 时结果错误，`x=1.2` 等小值正常
- **原因**：`int arr[100000]` 中 `arr[13] = 13! = 6,227,020,800` 超过 `int` 最大值（约 21 亿），发生溢出变为负数或垃圾值。`x=5` 需要算到约第 20 项，`arr[13]` 溢出后 `pow(5,13)/arr[13]` 得到异常值，循环提前终止
- **正确做法**：`double arr[1000]`，`double` 可表示到约 1.8×10³⁰⁸，远超题目需要的阶乘范围

#### 错误 2：`for` 循环条件前置导致漏掉最后一项
- **表现**：`x=5` 时结果 148.4131，正确应为 148.4132
- **原因**：
  ```c
  for(k = 0; pow(x,k)/arr[k] >= 0.00001; k++){
      ex += pow(x,k)/arr[k];
  }
  ```
  `for` 循环**先检查条件，再执行循环体**。当第 20 项 ≈ 0.000039 < 0.00001 时，条件为假，循环直接退出，第 20 项没被加进去。题目要求"最后一项的绝对值小于 0.00001"，也就是说最后加进去的那一项应该 < 0.00001，但这段代码把它漏掉了
- **正确做法**：改成"先加后判断"的方式

#### 错误 3：`do-while` 检查"下一项"导致仍然少一项
- **表现**：改成 `do-while` 后，`x=5` 仍然 148.4131
- **原因**：
  ```c
  do {
      ex += pow(x, k) / arr[k];
      k++;
  } while (pow(x, k) / arr[k] >= 0.00001);
  ```
  `do-while` 虽然先加后判断，但判断的是**下一项**（k+1）。当第 21 项 ≈ 0.0000093 < 0.00001 时退出，第 21 项没被加。而第 21 项恰好是把结果从 148.4131 推到 148.4132 的关键
- **正确做法**：判断**当前项**而非下一项，即 `for(;;) { 加当前项; if(当前项 < 0.00001) break; }`

#### 错误 4（最终正确写法）：`for + break` 判断当前项
- **正确代码**：
  ```c
  for (k = 0; ; k++) {
      double term = pow(x, k) / arr[k];
      ex = ex + term;
      if (term < 0.00001) break;
  }
  ```
- **关键区别**：判断的是**刚刚加进去的这一项**，而不是下一项。当 `term < 0.00001` 时，这一项已经加进去了，然后才退出

### 三种循环写法对比

| 写法 | 判断时机 | 判断对象 | x=5 最后加的是 | 结果 |
|------|---------|---------|--------------|------|
| `for(;条件;)` | 加之前 | 当前项 | k=19 | 148.4131 ❌ |
| `do-while(条件)` | 加之后 | 下一项 | k=20 | 148.4131 ❌ |
| `for+break` | 加之后 | 当前项 | k=21 | **148.4132** ✅ |

## 优化与拓展

- **不用阶乘数组的递推写法**（推荐）：
  ```c
  double sum = 1.0;      // 第0项
  double term = 1.0;     // 当前项
  for (int i = 1; term >= 0.00001; i++) {
      term = term * x / i;   // 递推下一项
      sum = sum + term;
  }
  ```
  优势：不需要 `pow()` 和阶乘数组，避免大数溢出，数值更稳定

- **递推公式推导**：
  ```
  第k项 = xᵏ/k!
  第k+1项 = xᵏ⁺¹/(k+1)! = (xᵏ/k!) × x/(k+1) = 第k项 × x/(k+1)
  ```
  所以 `term = term * x / (k+1)` 就是下一项

## 关键知识点总结

1. **循环终止条件的位置决定"最后一项"是谁**：`for` 条件在前 → 漏最后一项；`do-while` 检查下一项 → 漏一项；`for+break` 检查当前项 → 正确
2. **阶乘必须用 `double` 或 `long long` 存储**：`int` 到 13! 就溢出
3. **递推公式优于分别计算**：`term = term * x / k` 比 `pow(x,k) / k!` 更高效、更精确
4. **浮点精度边界问题**：当差值刚好卡在四舍五入边界（如 0.00005），差一项就可能导致结果差 1
