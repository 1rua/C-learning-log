# 习题3-3 出租车计价 - 复盘

## 题目要求

根据出租车收费标准计算车费：
- 起步里程 3 公里，起步费 10 元
- 超起步里程后 10 公里内，每公里 2 元
- 超过 10 公里以上部分加收 50% 回空补贴，即每公里 3 元
- 等待时间按每 5 分钟 2 元计收（不足 5 分钟不收费）

输入：行驶里程（精确到小数点后 1 位）和等待时间（整数，分钟）
输出：车费（元），四舍五入保留到元

## 本题考点

- `scanf` 读取 `double` 类型：**必须用 `%lf`**（`%f` 只对应 `float`）
- `double` 与 `int` 的混合运算：表达式结果类型为 `double`
- 浮点数赋值给 `int` 时的截断陷阱：截断 ≠ 四舍五入
- 四舍五入的实现：`(int)(表达式 + 0.5)`
- 整数除法（`time / 5`）实现「不足 5 分钟不收费」
- `if-else if-else` 多分支分段函数
- 等待时间的计费逻辑应覆盖所有里程段（不是只在 >10 公里时才加）

## 错误记录

### 语法错误

#### 错误 1：`scanf` 用 `%f` 读取 `double` 类型
- **表现**：测试点 1（5.1 公里不等待）和测试点 2（12.5 公里等待）答案错误，但测试点 0（2.6 公里）和测试点 3（3 公里）正确
- **原因**：`%f` 告诉 `scanf` 写入 4 字节（`float`），但 `km` 是 `double`（8 字节）。只有前 4 字节被正确写入，后 4 字节是栈上的随机值，导致 `km` 的值完全错乱。测试点 0 和 3 的 `km` ≤ 3，恰好没参与金额计算，所以侥幸通过
- **正确做法**：
  ```c
  double km;
  scanf("%lf %d", &km, &time);  // double 必须用 %lf
  ```

### 逻辑错误

#### 错误 2：浮点数直接赋值给 `int`，截断而非四舍五入
- **表现**：测试点 2（12.5 公里, 9 分钟等待）期望 34，截断后得到 33
- **原因**：`cost = 24 + 3 * (km - 10) + 2 * (time / 5)` 中，`km` 是 `double`，整个表达式结果是浮点数（33.5），赋值给 `int cost` 时直接截断为 33，而非四舍五入到 34
- **正确做法**：加 0.5 再强制类型转换：
  ```c
  cost = (int)(24 + 3 * (km - 10) + 2 * (time / 5) + 0.5);
  ```

## 优化与拓展

### 最终正确代码

```c
#include <stdio.h>

int main(void) {
    double km;
    int time, cost;
    scanf("%lf %d", &km, &time);

    if (km <= 3) {
        cost = (int)(10 + 2 * (time / 5) + 0.5);
    } else if (km > 3 && km <= 10) {
        cost = (int)(10 + 2 * (km - 3) + 2 * (time / 5) + 0.5);
    } else {
        cost = (int)(24 + 3 * (km - 10) + 2 * (time / 5) + 0.5);
    }

    printf("%d", cost);
    return 0;
}
```

### 优化建议：减少重复代码

等待时间计费 `2 * (time / 5)` 在每个分支都出现，可以提前计算：

```c
int wait_fee = 2 * (time / 5);  // 整除，不足5分钟自动为0

if (km <= 3) {
    cost = (int)(10 + wait_fee + 0.5);
} else if (km <= 10) {
    cost = (int)(10 + 2 * (km - 3) + wait_fee + 0.5);
} else {
    cost = (int)(24 + 3 * (km - 10) + wait_fee + 0.5);
}
```

### 其他实现思路

- 可以用纯整数运算避免浮点数四舍五入问题：将公里数乘以 10 转为整数（因为题目保证精确到小数点后 1 位），所有计算用整数完成，最后再转回元
- 但考虑到计算中涉及 `2 * km` 和 `3 * km`，浮点数方案更直观

## 关键知识点总结

### 1. `scanf` 读 `double` 必须用 `%lf`

| 函数 | `float` | `double` |
|---|---|---|
| `scanf` | `%f` | **`%lf`**（必须加 `l`） |
| `printf` | `%f` | `%f`（`%lf` 也可，等价） |

> **为什么不一样？** `printf` 的可变参数会进行默认参数提升，`float` 自动提升为 `double`，所以 `printf` 看到的永远是 `double`。但 `scanf` 通过指针传递，没有类型提升，必须精确匹配：`float*` 用 `%f`，`double*` 用 `%lf`。

### 2. 浮点数赋值给 `int` 是截断，不是四舍五入

```c
int x = 3.9;  // x = 3（截断，不是 4）
int x = (int)(3.9 + 0.5);  // x = 4（四舍五入）
```

### 3. 整数除法天然实现「不足则无」

```c
time / 5  // 整除：4/5=0, 5/5=1, 9/5=1
```

这个技巧在「每 N 个一组计费」的场景中非常实用。

### 4. 排查「部分测试点通过、部分不通过」的思路

当测试点 0 和 3 通过、1 和 2 不通过时，要观察通过的测试点有什么共同特征。这里 0 和 3 的 km 都 ≤ 3（没参与计算），说明问题出在 km 相关的计算上——要么是读取 km 的值不对（`%f` vs `%lf`），要么是 km 参与运算后的处理有问题（截断 vs 四舍五入）。
