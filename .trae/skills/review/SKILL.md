# 复盘

当用户发送「复盘」「review」等关键词时，按以下流程为当前题目生成复盘文档。

## 触发关键词

- 复盘
- review

## 执行流程

### 1. 确定题目和文件夹

1. 根据当前对话上下文确定题目名称
2. 找到该题目对应的子文件夹（如 `编程题/2输出倒三角图案/`）
3. 在该子文件夹下创建复盘文件：`题目名-复盘.md`

### 2. 复盘内容要求

#### 本题考点（必须）
- 题目涉及的核心知识点
- 考查的 C 语言概念和技能
- 相关算法或数据结构（如有）

#### 错误记录（如有则写，无则跳过）
- **逻辑错误**：解题思路误区、边界条件、循环判断、输出格式等问题
- **语法错误**：编译错误、语法陷阱、格式控制符、符号错误等

> **重要**：如果代码正常运行且提交结果无错误，**不要强行列出错误**。可以给出优化建议或其他实现方式，若都没有则直接跳过此部分。
>
> **格式错误处理**：如果评测结果显示"格式错误"，但该格式问题**不属于题目明确要求的输出格式**（如题目未要求特定空格/对齐，只是OJ系统误判），则**不记录为错误**。只记录因**未按题目明确要求**导致的格式问题。

#### 优化与拓展（可选）
- 更优的算法思路
- 代码简洁化建议
- 其他实现方式对比
- 性能优化方向

### 3. 复盘文件格式

```md
# 题目名 - 复盘

## 题目要求

（简述题目要求）

## 本题考点

- 知识点 1
- 知识点 2
- 知识点 3

## 错误记录（无则删除此节）

### 逻辑错误

#### 错误 1：……
- **表现**：……
- **原因**：……
- **正确做法**：……

### 语法错误

#### 错误 1：……
- **表现**：……
- **原因**：……
- **正确做法**：……

## 优化与拓展（可选）

- 优化建议 1
- 其他实现思路

## 关键知识点总结

（总结本题的核心知识点和易错点）

## 可以继续练的方向

- 相关练习 1
- 相关练习 2
```

### 4. 复盘完成后的反馈

创建复盘文件后，向用户简要说明：
- 复盘文件已创建的位置
- 本题的核心收获
- 建议继续练习的方向

### 5. 复盘后关联其他复盘（自动执行）

复盘文件创建完成后，**必须**执行以下关联步骤：

#### 5.1 扫描已有复盘文件

1. 扫描项目文件夹中所有 `*-复盘.md` 文件（排除当前刚创建的）
2. 读取每个复盘文件的内容，提取：
   - **本题考点** 中的知识点列表
   - **错误记录** 中的错误类型和原因
   - **关键知识点总结** 中的核心概念

#### 5.2 匹配关联内容

将当前复盘与已有复盘进行比对，找出：

- **相同知识点**：两个复盘都涉及同一 C 语言概念（如 `整数除法`、`for 循环`、`scanf 格式控制`）
- **相似错误**：两个复盘记录了同类型错误（如 `变量未初始化`、`printf 格式符错误`、`循环边界错误`）
- **递进关系**：当前题目是之前题目的延伸或变体（如从 `求N分之一序列` 到 `求交错序列`）

#### 5.3 建立相互链接

在**当前复盘文件**底部新增 **"相关复盘"** 章节：

```md
## 相关复盘

### 相同知识点
- [练习2-12 输出华氏-摄氏温度转换表 - 复盘](相对路径/练习2-12 输出华氏-摄氏温度转换表-复盘.md) — 同样涉及 `整数除法` 陷阱
- [计算物体自由下落的距离 - 复盘](相对路径/计算物体自由下落的距离-复盘.md) — 同样涉及 `printf` 格式控制

### 相似错误
- [练习2-12 输出华氏-摄氏温度转换表 - 复盘](相对路径/练习2-12 输出华氏-摄氏温度转换表-复盘.md) — 同样犯了 `整数除法导致精度丢失`

### 递进练习
- [练习2-14 求奇数分之一序列前N项和 - 复盘](相对路径/练习2-14 求奇数分之一序列前N项和-复盘.md) — 在 `求N分之一序列` 基础上增加符号交替
```

同时，在**已有关联的复盘文件**底部也追加反向链接。

> **链接格式**：使用 Markdown 相对路径链接 `[显示文本](相对路径)`，确保在 VS Code 中可点击跳转。
> **路径规则**：相对路径从当前复盘文件所在目录计算。

#### 5.4 关联原则

- **精准匹配**：只关联真正相关的内容，不要强行关联
- **双向链接**：当前复盘和已有复盘都要互相引用
- **分类清晰**：按 "相同知识点"、"相似错误"、"递进练习" 分类
- **说明原因**：每个链接后简要说明关联原因
- **如无则不写**：如果没有找到相关复盘，跳过此步骤，不要写 "暂无"

### 6. 复盘后更新学习进度

复盘关联完成后，**必须**检查并更新学习进度文件：

#### 6.1 检查学习进度文件

1. 检查项目根目录是否存在 `学习进度.md`（或 `学习报告.md`、`进度.md`）
2. 如不存在，创建该文件

#### 6.2 更新内容

将当前题目的学习记录按以下格式追加到进度文件中（**最新内容放在最前面**）：

```md
## 2025-05-13 — 练习2-13 求N分之一序列前N项和

- **状态**：✅ 已完成 + 已复盘
- **涉及知识点**：`for` 循环、`double` 浮点数、整数除法陷阱、`printf` 格式控制
- **错误记录**：
  - 整数除法导致结果错误（`1/n` → `1.0/n`）
  - 变量未初始化（`double sum` 未赋初值）
- **复盘文件**：[练习2-13 求N分之一序列前N项和 - 复盘](编程题/10练习2-13/练习2-13-复盘.md)
- **关联复盘**：
  - [练习2-12 温度转换表 - 复盘](编程题/9-练习2-12/练习2-12-复盘.md) — 同样涉及整数除法
```

#### 6.3 更新原则

- **倒序排列**：最新的学习记录放在文件最前面
- **去重检查**：如果该题目已有记录，更新而非重复追加
- **状态标记**：
  - `📝 已写代码` — 有 `.c` 文件但无复盘
  - `✅ 已完成` — 有代码且已复盘
  - `⚠️ 有错误待修正` — 复盘中有未解决的错误

### 7. 复盘后清理编译文件（必须执行）

复盘流程全部完成后，**必须**清理当前题目目录下的编译产物：

#### 7.1 扫描并删除编译文件

1. 进入当前题目所在目录
2. 查找以下类型的编译产物并删除：
   - **无扩展名的可执行文件**：编译 `.c` 文件生成的二进制可执行文件（如 `a.out`、与 `.c` 同名的无扩展名文件等）
   - **目标文件**：`*.o`、`*.obj`
   - **其他编译产物**：`*.exe`（如有）

#### 7.2 安全判断

- 只删除编译产物，**绝不删除** `.c` 源文件、`.md` 复盘文件等
- 如果无法确定某个文件是否为编译产物，保留不删
- 删除前确认文件不是源代码或项目文件

#### 7.3 清理完成后

向用户简要说明清理了哪些文件。
